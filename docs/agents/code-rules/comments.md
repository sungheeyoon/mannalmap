색인은 `CODING_STANDARDS.md` 다.

## 주석과 ADR 참조

- 주석은 한국어 산문이다. 식별자 · 인용 · 명령줄만 영어다.
- 주석은 지금 참인 것만 적는다 — 불변식, 이름과 타입으로 안 보이는 실패 방식, 이 모양을 고른 기술적 대가. 옛 구현 · 버린 안 · 결정의
  날짜와 경위는 ADR · `docs/product/prd-changelog.md` · `docs/notes/` 에 있다 — 근거가 필요하면 지금 유효한 ADR 하나를 가리킨다. 옛 주석은
  그 파일을 고칠 때 손댄 자리 둘레만 지운다 — 주석만 지우는 전역 정리 PR 은 열지 않는다.
- 제품 코드 주석의 날짜는 `scripts/code-rules.test.ts` 가 잡는다(있던 자리는 `scripts/dated-comments.json` — 날짜를 지우면 목록에서도 지운다).
  예외는 밖의 문서를 확인한 날 하나 — 출처 곁에 `확인 YYYY-MM-DD` 꼴로. 바로 앞이 「운영자 · 조율자」면 사람의 답이라 예외가 아니다.
- 결정은 `ADR 0078` 꼴(네 자리, 띄어쓰기 하나, 여럿은 `ADR 0072·0078`), 이슈는 `#67` — 표기와 실제 파일은 시험이 확인한다.
- TODO · FIXME · XXX · HACK 은 린트(`NO_LOOSE_ENDS`)와 시험이 잡는다. 미결은 `docs/product/gaps.md` 의 `G-nn` 줄이나 이슈다.
- 시험 이름은 참인 문장이다 — `it('src/lib 은 app 과 관문을 모른다')`. 무엇을 확인한다가 아니라 무엇이 참이다.
