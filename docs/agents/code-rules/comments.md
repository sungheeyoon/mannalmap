# 코드 규칙 — 주석과 ADR 참조

색인은 `CODING_STANDARDS.md` 다.

## 주석과 ADR 참조

- **주석은 한국어 산문**이다. 식별자 · 인용 · 명령줄만 영어다(2026-09-22 에 주석 18,415 줄 중 14,049 줄에
  한글이 있었고, 나머지는 인용과 명령이었다).
- **주석은 지금의 것만 적는다(2026-10-05)** — 지금 참인 불변식, 이름과 타입으로 안 보이는 실패 방식, 이 모양을
  고른 기술적 대가. 「무엇을 한다」는 이름이 말한다. **옛 구현 · 버린 안 · 운영자 결정의 날짜와 경위는 주석에 두지
  않는다** — 결정은 ADR, 날짜별 변경은 `docs/product/prd-changelog.md`, 사정은 노트(`docs/notes/`)가 든다. 결정 근거가
  필요하면 **지금 유효한 ADR 하나**를 가리킨다. 기존 주석은 **그 파일을 고칠 때 손댄 자리 둘레만** 걷는다 — 주석만
  걷는 전역 정리 PR 은 열지 않는다.
- **주석에 날짜를 새로 적지 않는다** — 제품 코드(웹 `src/` · `app/` · `proxy.ts`, 앱 `mobile/src`, 시험 · 생성 파일 제외)의 주석에 선
  `YYYY-MM-DD` 는 `scripts/code-rules.test.ts` 가 `파일 :: 날짜` 지문으로 세고, 있던 자리는 `scripts/dated-comments.json` 이 든다 — 줄어들기만
  한다(탈출구와 같은 결, `docs/agents/code-rules/escapes.md`). 위 줄대로 손댄 자리의 날짜를 걷으면 그 목록에서도 지운다. 낱말(「운영자」 ·
  「결정」)이 아니라 날짜를 세는 까닭은 「(2026-10-11)」 같은 맨 날짜도 경위라서다. **예외는 밖의 문서를 확인한 날(출처 날짜) 하나** —
  `확인 YYYY-MM-DD` · `YYYY-MM-DD 확인` 꼴로 출처 곁에 적는다. 남의 문서는 바뀌므로 언제 읽었나가 지금도 참이다. 바로 앞이 「운영자 · 조율자」면
  사람의 답이라 예외가 아니다.
- **결정은 `ADR NNNN` 으로 가리킨다.** 네 자리, 띄어쓰기 하나(`ADR 0078`), 여럿은 `·` 로
  (`ADR 0072·0078`). 붙여 쓰거나 하이픈으로 잇거나 자릿수를 줄이지 않는다 — 시험이 그 표기를 센다.
  전부 실제 파일을 가리키는지 시험이 잰다(2026-09-22 에 806 건 · 264 파일). 이슈는 `#67` 이다.
- **TODO · FIXME · XXX · HACK 을 남기지 않는다**(0건 — 웹 · 앱 · 시험 · 뿌리 설정의 주석. 린트 `no-warning-comments`(`eslint-code-rules.cjs` 의 `NO_LOOSE_ENDS`)와
  `scripts/code-rules.test.ts` 「주석에 TODO · FIXME · XXX · HACK 이 없다」가 잰다). 미결은 간극 대장(`docs/product/gaps.md`)의
  `G-nn` 줄이나 이슈다(`docs/agents/delegation/decisions.md` 「결정 점검표」 아래). 코드 안의 TODO 는 아무도 안 세는 목록이다.
- 시험 이름은 **참인 문장**이다 — `it('src/lib 은 app 과 관문을 모른다')`. 무엇을 잰다가 아니라
  무엇이 참이다.
