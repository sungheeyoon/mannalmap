# 코드 규칙 — 레퍼런스

색인은 `CODING_STANDARDS.md` 다.

## 레퍼런스

**모르면 짓지 않고 한국 서비스를 찾는다**(ADR 0196 · 0255). 화면의 글자 · 배치 · 흐름 · 처리 상태(로딩 · 실패 · 빈 화면 · 확인 창) · 한도 숫자 ·
정책의 빈틈을 정할 때 쓰는 차례와 꼴은 여기 하나다. 운영자는 최종 확인만 하고 싶어 한다 — 사례를 찾아 정하고 보이는 것이 기본이다.

다른 자리 — 글자를 넣고 확인받는 법은 `docs/agents/code-rules/screen-copy.md` 「화면 문구」, 묻는 것과 사례로 정하는 것의 가름은
`docs/agents/delegation/decisions.md` 「정책 · 흐름의 빈틈」, 시안은 `docs/agents/delegation/working.md` 「화면은 시안 먼저」, 이미 찾은 사례는 `docs/context/references.md`.

### 찾는 차례

1. **이미 정한 것** — 정책 · ADR · PRD · 문구 대장. 있으면 따르고 레퍼런스로 다시 고르지 않는다
2. **같은 자리의 기존 꼴** — 같은 상태를 다루는 우리 화면(웹 · 앱)의 꼴 · 정렬 · 단추 차례. 다르게 하려면 까닭을 적는다
3. **한국에서 출시한 서비스** — 일반 이용자가 쓰는 비슷한 서비스(사주 · 운세 · 소개팅 앱, 토스 · 카카오 · 네이버 · 당근). 해외 사례는 문화가 달라
   보조로만 쓰고 그렇다고 적는다. 플랫폼 규정(Apple · Google · 카카오 로그인 규격)은 조건이지 사례가 아니다. 한국 고객센터 · 도움말 글과 후기는 웹 검색
   도구에 얕게 잡히니 직접 연다 — 네이버 블로그 검색 · 본문과 Play 상세(설명 · 스크린샷 주소)는 `curl` 로 바로 받힌다
4. **모든 폭과 정렬** — 우리가 내는 폭마다(모바일 390 · 데스크톱 1280) 보고, 단추 폭 · 아이콘의 세로줄 · 글자 자리 · 정렬을 숫자로 적어 우리 것과
   같은 숫자로 견준다. 앱만 있는 서비스는 그렇다고 적는다
5. **없으면** — 「실사례 없음」과 가장 가까운 사례를 적는다. 정책이나 새 흐름인데 사례가 없으면 짓지 않고 구조와 선택지를 보고한다
   (`docs/agents/delegation/decisions.md` 「정책 · 흐름의 빈틈」)

**한도 숫자**(사진 px · 용량 · 기간 · 글자 수)도 이 차례다 — 공식 도움말을 먼저 보고, 3자 가이드는 그렇다고 밝히고, 어림은 「어림」이라 적어 근거로 삼지 않는다.

### 남기는 꼴

한 사례는 한 줄 — **서비스 · 원문 인용**(글자면 그대로, 배치면 숫자) · **URL** · **확인 날짜** · **폭** · **확인 수준**. 「위와 같음」으로 앞 줄을 가리키지 않는다.

| 수준 | 뜻 |
| --- | --- |
| A | 1차 원문을 받아 그 문장을 직접 대조함. 실제 화면을 열어 본 것도 A(그림의 폭을 함께) |
| A′ | 1차 원문을 페이지 요약 도구로 읽음(문장 재대조 안 함) |
| B | 스토어 등록 설명 원문 — 개발사가 그렇게 **말한** 것까지만 안다 |
| B′ | 공개 웹페이지 스크립트의 문구표(키 = 문장) — 어느 화면에서 뜨는지, 앱에도 같은지 못 봄 |
| C | 검색 요약만 읽음 |
| D | 2차(블로그 · 기사) |

### 남기는 자리

대화에만 두지 않는다 — 적어야 다음 사람이 다시 찾지 않는다.

| 무엇 | 자리 |
| --- | --- |
| 넣은 글자 | 그 무리 파일의 대장 「확인 전」 절 — 줄마다 출처 칸(`docs/agents/code-rules/screen-copy.md` 「화면 문구」) |
| 결정 | 그 ADR 의 「까닭」 절 — 사례 · 원문 · URL · 확인 날짜와 그래서 왜 이렇게 정했나 |
| 여럿을 견준 사례 표 | 그 `G-nn` 의 기록 파일(`docs/product/gaps/records/`) |
| 다시 쓸 레퍼런스 | `docs/context/references.md` 의 그 화면 꼴 — 위 자리에 적은 것을 한 줄로 옮기고 쓴 자리를 단다 |
| 레퍼런스 그림 · 우리 그림 | 저장소 밖 제 폴더(`docs/agents/delegation/done.md` 「끝났다는 것」) — 커밋하지 않는다 |
