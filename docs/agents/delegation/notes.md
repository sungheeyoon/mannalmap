# 위임 규약 — 세션 기록

색인은 `docs/agents/delegation.md` 다.

## 세션 기록 — `docs/notes/`

새 기억은 저장소에 적는다 — 규약은 위임 규약, 절차는 `docs/ops/runbook.md`, 결정은 ADR, 틈은 `docs/product/gaps.md`,
그 밖의 사정은 `docs/notes/`(차례 `docs/notes/README.md`)에 날짜와 함께. 노트는 요구사항도 규칙도 아니다 — 코드가 왜 이 모양인지 되짚을 때 연다.

**라운드 노트는 다른 데 없는 것이 있었을 때만 쓴다** — 무인 라운드의 권한 봉투, 판단과 그 까닭, 배운 것, 헤맨 것.
머지 목록은 PR, 배포 SHA 와 smoke 값은 #770 의 배포 댓글, 남은 일은 간극 대장이 원본이다 — 노트는 PR 번호 · `G-nn` 으로 가리키기만 한다.
노트도 가지 → PR → `--auto` 로 넣고, 차례의 「최근」 맨 위에 줄을 더한다. 아직 main 에 없는 경로 · ADR 번호는 적지 않고 PR 번호로 가리킨다 — 참조 시험이 실패한다.

**헤맨 것 · 회고 줄마다 `→ 놓은 자리`(파일 · 절 · `G-nn` · `#NNN`)를 단다** — 「다음 retro 로」는 자리가 아니다. 절은 「…」로 적고 저장소 문서의
절 머리 하나를 다 불러야 한다(제 노트의 머리 · 머리의 한 토막은 안 된다).

**회고(`/retro`)는 같은 자리에서 두 번 넘어졌을 때 돈다** — 매 세션이 아니다. 놓는 자리는 이 차례로 고른다.

1. 기계 검사 — 린트 · 시험 · 훅이 잡게 한다
2. 효과 없는 지시를 지운다 — 같은 실수가 지시가 있는데도 났으면 그 지시는 일을 안 한다
3. 길잡이 한 줄 — 원본 한 곳에. 한 줄을 더하면 한 줄을 지운다

리뷰 때 보는 판단 규칙은 `docs/agents/code-rules/` 에 놓는다.

## 경로가 옮겨지면 — 고치는 것과 두는 것

지금을 말하는 문서(입구 · 역할 문서 · 위임 규약 · PRD · 간극 대장 · 운영 소스 주석)는 지금 자리로 고친다 — 시험이 확인한다
(`docs/agents/code-rules/locks.md` 「린트가 잠근 것 · 시험이 잠근 것」). ADR 본문 · 노트 · changelog 의 지난 줄 · 마이그레이션 주석은
그날의 기록이라 옛 경로째 둔다. 닫은 `G-nn` 의 기록 파일(`docs/product/gaps/records/`)을 지울 때도 지금을 말하는 문서의 링크만 고친다.
