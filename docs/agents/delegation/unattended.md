# 위임 규약 — 무인 라운드

색인은 `docs/agents/delegation.md` 다.

## 무인 라운드 — 운영자가 자는 동안

운영자가 「감사하고, 틀린 것은 고치고, 커밋 · 푸시하며 이어가라」고 맡기고 자는 라운드다. **무인 라운드는 권한 등급을 넓히지 않는다** —
`docs/agents/delegation/permissions.md` 「권한 등급」 표 안에서, 운영자가 시작할 때 준 범위만큼만 움직인다.

**권한 봉투는 시작할 때 한 번 적는다** — 그날 라운드 노트의 첫 줄에 무엇을 맡았는지. 운영자가 「알아서 계속」이라고만 했으면 아래가 기본값이다.

| 항목 | 기본값 |
| --- | --- |
| 코드 · 문서 수정, 작업 가지 커밋 · 푸시, PR 생성 · 갱신 | 허용 |
| gate 통과 뒤 `--auto` 머지 — 문서 PR · 정해진 문구 한 줄 | 허용 |
| 코드 PR 의 머지 | 바이패스 모드 라운드는 독립 검토(결정 PR) · CI 초록 뒤 조율자가 묻지 않고 머지하고 제 워크트리 · 가지도 정리한다. 아니면 PR 까지 만들어 아침 보고에 싣고 운영자 검토 뒤 머지(`docs/agents/delegation/coordinator.md` 「출시 흐름」) |
| main 직접 푸시 | 금지 — 보호 규칙이 막는다 |
| `docs/agents/delegation/decisions.md` 「결정 점검표」에 걸리는 PR | PR 까지 만들고 아침 보고의 「결정 대기」로. 바이패스 라운드에서 운영자가 이미 답한 결정이면 독립 검토 · CI 초록 뒤 머지 |
| 운영 `db push` | 묻지 않고 수행하고 본 값을 적는다 — `migration list` 의 remote 칸과 PostgREST 캐시. 마이그레이션이 든 PR 은 push 와 확인 뒤 `--auto` |
| 실호출 | 하지 않는다 — 명령과 확인할 값을 PR 에 적어 운영자에게 건넨다 |
| 운영 배포 | 바이패스 모드 라운드는 묻지 않고 라운드 끝에 한 번(ADR 0271). 아니면 운영자의 「배포」 답 뒤 |
| main 이 실패함 | 새 작업을 멈추고 먼저 복구한다(`docs/agents/delegation/working.md` 「시작하기 전에」) |

**머지 허락은 라운드를 열 때 말로 받는다** — auto 모드의 권한 분류기는 「진행」만으로는 `gh pr merge --auto` 를 검토 없는 머지로 막는다.
운영자가 제 `.claude/settings.local.json` 에 `Bash(gh pr merge --auto:*)` 를 넣어 두었으면 그 말 없이도 된다.

**자동으로 고쳐도 되는 경계** — 무엇을 고쳐 PR 로 올려도 되나(머지는 위 표).

- 기존 규칙 · 디자인 체계(`app/ui/`) · 접근성 · 이미 승인된 문구나 디자인을 어긴 것을 되돌리는 수정
- 뜻을 바꾸지 않는 화면 다듬기(여백 · 정렬 · 반응형 · 포커스 · 오류 상태) — 근거는 전후 그림과 고친 자리의 로컬 시험
  (`docs/agents/test-map/what-to-run.md`)이다. 그림 경로를 넘기면 조율자가 아티팩트로 보인다
- 결정 점검표의 항목 — 수정안과 PR 은 만들되 결정 대기, 권고는 한국 레퍼런스와 함께. 새 사용자 문구는 사후 확인이라 PR 까지 가고 「확인 전」으로 싣는다

**묶음으로 머지한다** — 지금 머지할 묶음과 순서를 정해 `npm run merge:sim -- <PR 번호들>`(머지할 순서대로)로 최신 main 위에 함께 합쳐 본 뒤,
하나씩 최신 main 위에서 gate → `--auto`. 묶음이 다 머지되면 main 의 CI 를 보고 다음 묶음으로 간다.

**아침 보고의 칸** — 머지된 것 · 결정 대기(PR 과 물을 표) · 직접 확인한 근거(`파일:줄` · 실행 결과) · 돌린 시험 · main 상태(CI · HEAD) ·
화면 전후 그림(아티팩트) · 안 한 것과 그 까닭. 보고는 대화로 끝난다 — 노트는 이 칸을 옮겨 적지 않는다(`docs/agents/delegation/notes.md` 「세션 기록」).
