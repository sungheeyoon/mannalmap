# 「인연이 열리면 알려 주세요」의 근거 — 알림 수단 · 동의 · 고지 (ADR 0223)

법률 자문이 아니다. 요건과 사실만 두고 **적법한지는 판정하지 않는다**(ADR 0182 · 0209). 원문을 열지 못한 것은 「확인 전」으로 둔다.

## 사실 — 코드가 하는 것

- 남기는 것: 사람마다 한 줄 — 계정 id 와 신청 시각(`supabase/migrations/20270110090000_the_member_asks_to_hear_when_the_match_opens.sql` 의 `match_open_alert`).
  무엇을 보낼지 · 연락처는 남기지 않는다.
- 받는 자리: 로그인한 홈의 한 줄, 인연이 닫혔다고 읽었을 때만(`app/me/home/match-open-alert.tsx` · `mobile/src/home/match-open-alert.tsx`). 누르기 전에
  「열리면 소식으로 알려 드릴까요?」가 선다 — 수단(서비스 안의 소식)을 말한다.
- 지움: 「알림 끄기」 · 탈퇴 처분(cascade) · 여는 날 소식을 넣은 뒤(`docs/ops/runbook/match-opening.md`).
- 보내는 것: 아직 없다. 여는 날 서비스 안의 소식(종 목록, `notification`) 한 줄로만 보낸다고 정했다 — 이메일 · 문자 · 푸시는 쓰지 않는다(ADR 0223 의 3).
- 세는 것: 운영자는 수만 센다 — `select count(*) from public.match_open_alert;`(개인을 가리키지 않는다, ADR 0105).

## 요건 1 — 영리목적의 광고성 정보 전송(정보통신망법 제50조)

- 제50조 제1항은 전자적 전송매체로 영리목적의 광고성 정보를 보내려면 수신자의 명시적 사전 동의를 받으라고 한다. 조문 원문은
  <https://www.law.go.kr/법령/정보통신망이용촉진및정보보호등에관한법률/제50조> — **원문 확인 전**(2026-11-05 에 페이지 본문을 못 읽었다).
- 방송통신위원회 · KISA 「불법스팸 방지를 위한 정보통신망법 안내서」 — 2025년 12월 판(KISA-GD-2025-0037)이 <https://t1.kakaocdn.net/rocket/user-guide/latest-kisa-guide-1.pdf> 에 있다.
  **본문 확인 전**(2026-11-05, PDF 를 글자로 못 뽑았다). 같은 판의 보도자료 제목은 「'혜택 알림'·'정보제공' 등 모호한 표현으로 광고 동의 유도 안 돼」다
  (<https://www.kisa.or.kr/402/form?postSeq=2577>, 확인 2026-11-05 — 검색 결과의 제목).
- 이 저장소가 이미 적은 물음: 「다음 테스트 소식 받기」가 「새 기능 소식 받기」 꼴이 되면 광고성 정보 수신 동의가 되는지 본다(`docs/legal/privacy-v8-draft.md` 「선택 항목」).

**우리 사실과의 대조(판정 아님)** — 보내는 매체가 서비스 밖(이메일 · 문자 · 푸시)이 아니라 서비스 안의 소식 목록이다. 알림의 계기는 이용자의 누름(요청)이다.
알림의 내용은 「인연이 열렸어요」 한 가지이고 할인 · 다른 상품을 싣지 않는다. 서비스 안의 소식이 「전자적 전송매체를 이용한 전송」인지, 요청한 기능 개시
알림이 「광고성 정보」인지는 위 안내서 원문으로 가려야 하고 **판정하지 않았다**. 밖으로 보내는 수단(푸시 등)을 더하려면 이 물음을 먼저 닫는다.

## 요건 2 — 처리방침의 처리 항목 · 목적(개인정보 보호법 제30조)

- 처리방침은 처리 목적 · 처리 항목 · 보유기간을 적는다(제30조 제1항). 지금 게시본은 `notice-v14`(`src/lib/consent/notice.ts` 의 `NOTICE_VERSION`)이고 이 신청을 적지 않는다.
- 새로 남기는 것은 「인연 열림 알림 신청 여부 · 신청 시각」이다. 그것이 지금 적힌 「서비스 이용 기록」 안에 드는지, 목적 「요청하신 알림의 발송」을 새로 적어야
  하는지는 **운영자가 정한다**(ADR 0223 「정하지 않은 것」). 올린다면 처리 항목 표에 서는 후보 문장:
  「인연 열림 알림 — 신청 여부와 신청 시각 — 인연이 열릴 때 서비스 안의 소식으로 알리기 위해 — 취소 · 탈퇴하거나 알림을 보낸 때까지」.
