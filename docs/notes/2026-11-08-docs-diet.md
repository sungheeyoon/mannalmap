# 2026-11-08 — 문서 다이어트: 규칙 줄에서 덜어낸 일화 · 측정값

2026-11-08 감사를 일로 바꾼 라운드의 레인 C 다. 규칙은 그대로 두고 **규칙 줄에 붙은 일화 · 날짜 · PR 번호 · 경위**를 덜어냈다.
덜어낸 것 가운데 다른 데 없던 것을 여기 모은다 — 요구사항도 규칙도 아니다. 규칙의 자리는 각 절이 가리키는 원본이다.
같은 라운드에서 운영 절차 넷의 꼬리표는 #1078, `docs/guide.md` 의 규칙 사본은 #1079 가 덜어냈다.

## 조율자 세션(`docs/agents/delegation/coordinator.md`)에서 덜어낸 일화

- **물을 표는 PR 이 열린 그 차례에(2026-10-22)** — 결정 PR 다섯을 검토 · CI 뒤로 미뤄 몇 시간 들고 있었는데 답은 넷 다 권고안이었다.
- **브리프는 해결책을 정하지 않는다(2026-11-07)** — 법적 글이 앱 빌드에 묶인 문제를 링크 한 줄로 막으려던 #1063 을 닫고 #1064 · #1066 으로 다시 풀었다.
- **확인 전의 가설(2026-09-28)** — 세션 메모가 결정의 「대가」를 「운영자 판단 남음」으로 옮겼고 조율자가 원본을 안 보고 운영자에게 다시 물었다.
  문구 대장에 옛 서비스명 · 틀린 현재 문구 · 오류 경계가 보장 못 하는 문장(「저장된 값은 그대로 있습니다」)이 들어간 것은 코드가 아니라 옛 대장과 감사 보고를 보고 썼기 때문이다.
- **다른 환경의 결과(2026-11-07)** — 로컬 npm 11.14 가 `npm ci` 를 거절한 것을 「다음 EAS 빌드가 깨진다」로 전했는데, EAS 의 npm 은 11.6.2 였고 그 잠금을 받았다. npm 버전 어긋남은 이제 CI 가 확인한다(#1068).
- **결정 PR 의 두 번째 검토(2026-10-08 · 10-22)** — 「실패했을 때 열리는가」에 걸린 #539 를 조율자 혼자 보고 머지를 걸었고, 꽉 찬 보관함에서 실패하면 한 사람이 사라지는 결함을 바깥 리뷰가 잡았다.
  검토 뒤 고침이 CI 바퀴를 하나 더 태웠다(#791 · #792) — 그래서 push 전 로컬 diff 로 받는다.
- **`보류` 줄(2026-10-20)** — 운영자 실기기 · 운영 확인이 남은 줄 다섯을 문구 결정으로 보고했다.
- **노트 커밋 전 시험(#297)** — 없는 ADR 번호와 차례에 빠진 노트로 조율자의 직접 커밋이 main 의 시험을 실패시켰다.
- **`git push origin HEAD`(2026-10-07)** 가 원격에 새 가지를 세웠다.
- **`merge:sim`(2026-09-28)** — PR 마다 초록이어도 한 PR 의 새 잠금이 다른 PR 의 새 파일을 몰라 합치면 실패했다.
- **임시 파일** — 스크래치 폴더를 두 에이전트가 같이 써서 서로 덮었다(#209 · #750 · #751).
- **병렬로 부딪힌 것** — ADR 번호 · pgTAP 파일 번호 · 마이그레이션 타임스탬프 · gaps 의 같은 줄. 문구 대장 절 번호는 ADR 0169 뒤로 무리 파일 접두라 안 부딪힌다. 원본은 `docs/agents/delegation/parallel.md` 의 표다.
- **「CI 기다림」(2026-10-11)** — 충돌한 PR 에는 CI 가 돌지 않아, 보고만 믿은 조율자 앞에서 #627 이 일곱 시간 멈췄다. 제목만 고친 PR 은 검사가 다시 안 돌았고(#633),
  `gh pr update-branch` 뒤 `--auto` 가 풀렸다(#635).
- **꺼진 에이전트(2026-10-22)** — db 에이전트가 「#790 머지를 기다린다」를 남기고 끝났는데 조율자가 「머지 중」이라고 보고했고, 사슬이 몇 시간 멈췄다.
- **검토자의 판정(2026-11-07)** — 「DB 를 먼저 올리면 운영에서 깨지는 곳이 없다」를 「깨지는 곳 없다」로, 「지적을 고쳤다」를 「모두 해결」로 옮긴 보고를 운영자 쪽 검토가 잡았다.
- **끝난 워크트리(2026-09-24)** — 워크트리 16개가 스택 자리 1~9 를 쥐어 새 에이전트의 `stack:slot --auto` 가 거절됐다. 이어 받기에서는 다른 워크트리가
  `decide/refund-refusal-rereads` 를 쥐어 새 에이전트가 체크아웃하지 못했다(#798, 2026-10-22).

## 권한 등급(`docs/agents/delegation/permissions.md`)에서 덜어낸 이력

- 등급 3 의 잠금 — 2026-11-05 에 운영자가 테스트 코드 없이 누구나 가입하게 정해(#1007) 단계가 공개 출시로 옮겨졌고, 켤 목록 스물셋을 다 `ask` 에 넣었다(#1011).
  2026-11-07 에 운영자가 「배포 전에만 물으면 된다」고 좁혔다 — 그 사이(11-05 ~ 11-07)에는 `db push` · 운영 SQL · `gh pr merge`(`--auto` 까지)를 도구가 물었다.
  원본은 ADR 0093 「배포만 묻는다」.
- `gh pr merge --auto` 는 2026-09-22 부터 gate 를 기다린다(ADR 0082). 보호 규칙의 strict 는 2026-09-23 에 켜졌다가 2026-10-12 운영자 승인으로 꺼졌다 — 켜져 있던 동안 `BEHIND` 가 `--auto` 를 막았다(#143).
- `--auto` 없는 즉시 머지가 2026-09-20 에 한 번 있었다 — 그때는 머지가 곧 배포였다.
- 「잠그지 않은 것」 — 2026-09-23 의 측정값: `.claude/settings.local.json` 에 「항상 허용」으로 쌓인 `Bash(gh pr *)` · `Bash(npx supabase *)` · `Bash(git push *)` 가 있는 동안
  `ask` 21개가 켜져 있어도 `gh pr merge` 는 묻지 않았고, 그 세 줄을 지우자 물었다. 같은 날 `deny` 는 `cd x && git push --force-with-lease` 를 막지 않았다(작업 가지).
  2026-10-07 에 PR 가지가 force push 로 다시 쓰였다 — `deny` 가 깃발이 `git push` 바로 뒤일 때만 걸렸다.
- 「공식 운영에 들어가면 켜는 잠금」에 간극 대장 줄이 없던 까닭(2026-09-23, #142) — 단계를 옮기기 전에는 아무도 그 절을 수행하지 않았다.

## 로컬 환경의 함정(`docs/agents/delegation/local-env.md`)에서 덜어낸 측정값

- **워크트리 격리** — 2026-10-14 라운드의 에이전트 다섯이 다 겪었다. `vercel` 파이프는 2026-10-18 배포 에이전트들, `gh -q` 는 2026-10-23 라운드의 에이전트 넷 다(같은 날 다른 세션에서는 통과).
  2026-10-30 Expo 라운드에서 `cd` 를 붙인 `git`, 2026-11-07 에 `git -C` · `cd … &&` 뒤의 아무 명령 · `--jq` 의 `\(…)` 템플릿.
- **vitest 시간 초과(2026-11-02)** — 15회 실패 전부 시간 초과 · 단언 불일치 0. `calibration` 훅은 단독 6~7초, `--maxWorkers=4` 8~9초, `=8` 14~19초, 기본 23~28초(각 3회).
  `--maxWorkers=4` 의 벽시계는 65~87초로 겹쳐 느려지지 않았다.
- **CI 에서는 안 난다(2026-10-31)** — verify 의 실패 실행 200개(2026-09-11~10-30)에 포함된 실패한 `core` · `policy` job 49개에 시간 초과가 0건이었다(옛 이름 `fast` 의 job 은 안 셌다).
- **빌드의 `leaves the filesystem root`** — 2026-10-07 에 났고, 2026-10-10 #604 에서는 `.claude/worktrees/` 아래에 `cp -a --reflink=auto` 로 복사한 `node_modules` 로 빌드가 됐다.
- **`node_modules` 복제(2026-09-27)** — 메인 폴더 안의 워크트리 다섯 벌이 8.3GB 였다.
- **`mobile/node_modules` 링크** — 2026-11-06 메인에는 `expo-iap` 가 없었다.
- **WSL 줄** — `/tmp` tmpfs(2026-10-08) · apt 의 `gh` 2.46(2026-10-06 에 2.102.0 으로) · Docker Desktop 엔진(2026-10-31) · WSL 연동(2026-10-12). 2026-10-24 에 맥으로 돌아왔고

- **씨앗의 종료일** — 2026-11-06 전에는 `2026-10-31` 이 박혀 있어 손으로 올렸다(#1027 이 오늘에서 세게 바꿨다).
- **에뮬레이터 전수 재기(2026-10-31)** — #927 이 이 길로 웹 번들에 안 보이던 셋을 찾았다. 개발 번들의 홈은 2026-11-02 에 34~49초.
