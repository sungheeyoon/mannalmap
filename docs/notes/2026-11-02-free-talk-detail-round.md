# 무료 연결 · 상세 궁합 라운드 (2026-11-02)

요구사항이 아니다. 정책은 PRD `docs/product/prd/matching.md` §6.6, 결정은 ADR 0215, 진행은 #961, 지금 상태와 켜기 전 조건은 `docs/product/gaps.md` 의 G-130 이 든다.
여기는 다른 문서에 없는 사정만 적는다.

## 권한 봉투

운영자가 세부를 맡겼다(2026-11-02, 원문은 #961 댓글). 합의 방향 안의 세부 UX · 문구 · 한도 · 재시도는 조율자가 정하고 구현 뒤 보고한다.

다시 묻는 것은 넷이다 — 합의를 넘는 과금 · 개인정보 · 동의 범위, 운영자 인증 · 실호출, 운영 DB · 배포 · 켜기, 실제 장애.
운영 DB 적용은 독립 재검토 뒤 마이그레이션 목록 · 검증 결과 · 순서 · 되돌리기의 실제 범위를 갖춰 한 번에 승인을 청한다.

## 조율자의 판단과 까닭

- **없는 단추로 물어 D11-2 를 다시 받았다.** 받은 사람의 선택을 「거절·차단 + 첫 말 1건」으로 물었는데, 대화에는 거절 단추가 없다. 있는 듯 물어 받은 답이라 무효로 보고
  다시 물었고, 운영자가 「답하거나, 그냥 두거나, 차단한다」로 답했다. 물음의 보기는 지금 화면에 있는 것인지 먼저 잰다.
- **스위치 경합을 처음에는 켜기 전 조건으로만 올렸다가 고쳤다.** 무료 클릭이 유료 예약이 되는 결함을 위험 기록으로 넘긴 것이 잘못이라는 지적을 받아 DB 가 기대 종류를 확인하게 했다(#987, ADR 0216).
- **#987 을 나누지 않았다.** 앱이 새 함수를 부르면 PR 을 나누는 규칙과 다르다. 머지가 아무것도 내보내지 않고 테스트 앱이 main 을 재야 해서이고, 대신 운영 DB 적용 전 묶음 배포를 금지로 적었다(ADR 0216).

## 배운 것 · 헤맨 것

- **「시험이 있다」는 시험의 틈을 말하지 않는다.** #975 의 재검토가 코드를 일부러 깨뜨려 봤더니 99곳 중 32곳이 초록이었다. 시험을 메운 뒤 113곳 중 초록 3이고,
  그 셋은 같은 뜻의 다른 줄이 받는 자리다(값은 #975 본문).
- **고침이 새 교착을 만들었고 차이 검토가 잡았다.** 앞선 지적을 고친 판에서 취소와 차단이 서로를 기다렸다. 고친 차이만 본 검토가 잡았다.
  나란히 돌린 판의 교착 0 은 끼어드는 순간을 강제하지 않으니 차례를 맞춘 재현이 근거다(#975).
- **앱 에이전트가 메인 로컬 스택을 reset 했다.** `db:reset` 의 대상이 메인 스택이었다. 함정과 하는 일은 `docs/agents/delegation/local-env.md` 에 옮겼다.
- **사용 한도로 멈췄다.** 라운드 중 사용 한도에 걸려 일이 끊겼다가 이어서 끝냈다.
- **오래 도는 표시가 일을 뜻하지 않았다.** 머지가 끝난 에이전트의 대기 명령이 8시간 남았고, 일부러 건 CPU 부하가 다른 에이전트의 시험과 겹쳐 부하가 50까지 올랐다. 부하 측정은 나란히 돌리지 않는다.
- **실호출 시험이 열쇠 없이 초록이었다.** 셸에 열쇠가 없으면 12콜이 다 실패해도 시험이 통과했다(코드로 찾음, #985). 초록은 호출이 다 됐다는 뜻으로만 읽는다.
- **나란히 낸 ADR 번호는 뒤 PR 을 앞 PR 머지까지 붉게 둔다.** 규약에 있는 일인데 에이전트 브리프에 없어 #986 이 다시 알아냈다.
