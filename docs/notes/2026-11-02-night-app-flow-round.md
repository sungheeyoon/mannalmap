## 조율자의 판단과 까닭

- **「내 사주를 저장하면 인연 찾기에 참여합니다」를 안 바꿨다.** 문구처럼 보여도 동의 · 공개 범위 정책이라 봉투 밖이다 — 아침 결정으로 넘겼다.
- **#954 의 검토 순서가 틀렸다.** 스위치는 꺼져 있지만 함수 14개를 바꾼 PR 인데, 조율자 브리프가 독립 검토 없이 `db push` 하게 뒀다.
  뒤늦게 검토해 문제 없음을 받았어도 순서 실수다. **운영 DB 를 바꾸는 결정 PR 의 검토는 push 전이다.**
- **궁합 입구를 되살렸다.** `/landing` 을 걷으면서 궁합 입구가 함께 사라진 것을 조율자가 잡아 #958 에서 되살렸다.
