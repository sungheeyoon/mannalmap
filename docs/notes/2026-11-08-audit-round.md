## 운영자 결정 · 판단과 까닭

- **처리방침 보충(G-153)은 `notice-v19` 로 갔다(ADR 0245, #1089).** 프로필 사진 · 소개를 선택 항목으로 들고 지금은 본인에게만 보인다고 적는다.
  그 문장이 참이려면 정지된 계정도 제 사진 · 소개를 지울 수 있어야 해서 ADR 0244 를 먼저 정했다(#1090 DB — 사진은 장마다 · #1091 웹 화면).
  설정의 참여 문구는 다섯 상태로 갈랐다(#1092).
- **「인터뷰 요청 받기」는 끄지 않고 없앴다(#1093).** 처음에는 가입 · 설정 · 처리방침에서만 빼고 DB 칸 · 문은 옛 앱 때문에 남겼는데(G-159),
  운영자가 「끄는 게 아니라 아예 없애」라 해 칸과 함수를 지웠다. 옛 웹 · 앱이 보내는 `p_contact` 인자만 받아 버린다 — 그 인자를 삭제하는 일은 G-160.
- **인연을 열 때의 조건을 대장 줄로 만들었다(G-158).** v19 의 「성인 확인을 마친 이용자에게만」이 성인 확인 스위치에 기대기 때문이다.
- 배포는 DB 와 웹을 갈라 올렸다 — 1차 웹 `5672ca4b`(17:44 KST) 뒤 `20270118090000` 을 17:48 에 올리고, 2차 웹 `ff46c722`(20:37 KST)로 코드를 DB 에 맞췄다. 값은 #770.

## 헤맨 것 · 틀린 것 — 놓은 자리

1. `/privacy` 에서 `notice-v19` 글자를 찾았다 — 버전 글자는 화면에 안 보이고, 그 버전에 새로 포함된 문장으로 확인한다 → `docs/ops/runbook/deploy.md` 「묶음 배포」 4.
2. 「접근 기록」이 무엇인지 몰랐다 — `npm run db:remote` 가 질의마다 남기는 접속기록 `audit.operator_access` 다 → `docs/ops/runbook/deploy.md` 「배포」.
3. `db push` 를 어느 폴더에서 부르는지가 `deploy.md` 에 없었다 — 워크트리에는 `supabase` 폴더의 `.temp`(연결 정보)가 없고, CLI 는 부르는 폴더의 마이그레이션을 올린다
   → `docs/ops/runbook/deploy.md` 「배포」의 마이그레이션 줄.
4. `scripts/ui-seed.mjs` 의 기본 닉네임이 부딪혔다 — 기본값이 `벗` + 꼬리표 끝 네 자리라, 같은 꼬리표로 두 번 만들거나 앞 시드와 끝 네 자리가 같으면 유일 색인에 걸린다
   → `docs/agents/delegation/local-env.md` 「로컬 환경의 함정」.
5. zsh 가 따옴표 없는 `[` · `?` · `*` 를 파일 이름으로 펼치려다 `no matches found` 로 멈췄다 → `docs/agents/delegation/local-env.md` 「로컬 환경의 함정」.
6. 문구 대장 번호를 브리프에서 미리 받지 않고 PR 을 열었다 — 규칙은 이미 `docs/agents/delegation/parallel.md` 「그 밖의 공유 번호」에 있고 `gate` 가 잡는다(ADR 0238). 규칙을 수행하지 않은 것이라 원본은 안 고쳤다.
