## 시간 초과의 원인 (#1160)

전체 vitest 의 반복 시간 초과는 로컬 기본 일꾼 열다섯(8코어 16스레드)이 무거운 시험을 혼자일 때보다 3~4배 느리게 한 것이었다 — 일꾼 넷이면 벽시계는 같고 겹쳐 돌려도 초록. 훅 시간 초과가 `skipped` 로 세어져 끝 줄의 실패 수가 줄어 보이는 것은 Vitest 의 셈이다(`Test Files … failed` 와 종료 코드에는 드러난다). 잰 표는 #1160 과 `docs/agents/test-map/kinds.md`.
권고(정책이라 하지 않음): 다른 에이전트가 전체 vitest 를 `scripts/heavy.mjs` 밖에서 돌리는 것이 겹침의 원천이다 — `npm test` 를 그 잠금으로 감쌀지는 운영자가 정한다.
