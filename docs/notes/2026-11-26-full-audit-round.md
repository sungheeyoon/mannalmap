## 조율자의 판단과 그 까닭

- **pstack 은 이 기계에 없었다** — 최소 코드 관점은 저장소의 죽은 코드 규칙과 knip 결과를 이름마다 grep 으로 다시 잰 것으로 대신했다. 진짜 죽은 파일은 둘뿐이었고, 나머지는 복사본 모으기였다.
- **레인은 파일로 갈랐다** — 같은 파일을 두 감사가 짚으면(앱 문구 시험의 주석 구멍은 시험 감사, 그 도구 열두 벌은 최소 코드 감사) 한 레인에 몰았다. 서로 겹친 것은 `scripts/layers.test.ts` 하나였고 `merge:sim` 이 초록이었다.
- **#1286 의 flow 가 붉었다** — `src/lib/push/index.ts` 는 node 가 직접 읽는 파일이라 확장자 없는 import 를 못 푼다. 그 파일만 UUID 식을 제자리에 두었다.
- **#1290 은 결정 PR 이라 독립 검토를 붙였고 한 번 되돌렸다** — 좁힌 검사 둘(문구 대장 색인의 없는 번호, 역할 문서 셋째 칸)이 ADR 이 「남긴다」고 한 것까지 걷었다. 검토자가 일부러 어긴 입력으로 초록인 것을 보였다.
- **시험 감사가 숨은 흔들림을 찾았다** — 최근 verify 20번 가운데 5번에서 e2e 10건이 다시 돌아 초록으로 접혔다(가장 잦은 것은 인연 `match.spec.ts`). #1285 가 job 요약에 수를 세운다.
