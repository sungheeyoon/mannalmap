# G-190 기록

표의 줄: [간극 대장 「공개 출시」의 G-190](../../gaps.md#공개-출시)

2026-11-27 무인 라운드의 앱 전수 점검(아티팩트(2026-11-27))이 「정할 것」으로 둔 줄이다. 기기는 안드로이드 에뮬레이터(1080×2400, 411×914dp) ·
Expo Go 58 · 가짜 서버(`mobile/scripts/measure/fake-server.mjs`, 인연이 닫힌 운영 상태)였고, 운영에 열린 33 라우트를 밝은 화면 전부와 다크 16 으로
177 장 찍었다(그림 속 이름 · 생년월일은 꾸민 것). 찍는 법은 `docs/agents/delegation/local-env.md` 「앱을 네이티브로 재기」.

같은 점검의 「바로 고칠 것」 열(뜻을 안 바꾸는 다듬기)은 같은 라운드의 화면 작업이 PR 로 고친다 — 이 기록 밖이다. 「정할 것」의 첫 줄인 첫인상 방향
(원인 다섯 — 스티커 꼴 오행 그림 · 장식으로 쓴 색 · 붓맛 명조 한 벌 · 알약과 그림자와 카드 속 카드 · 큰 글자와 성긴 밀도)은 G-185 에 있고, 운영자가 「일단 글꼴 바꾸는 건 안 할게」로
미뤘다(2026-11-27 낮, `보류`). 그래서 아래 고르기 · 비유 · 펼침의 꼴은 지금 글꼴 · 면 그대로 줄마다 정한다.

## 정할 것 — 열하나

줄마다 운영자 답(고친다 · 그대로 둔다 · 보류)을 받고, 고친 것은 그 PR 이 머지되면 여기서 지운다. 열하나가 다 지워지면 G-190 을 닫는다.
