# G-130 기록

표의 줄: [간극 대장 「공개 출시」의 G-130](../../gaps.md#공개-출시)

정책의 원본은 PRD §6.6 이다. 여기는 경과와 그 절에 맞출 자리만 든다.

## 2026-11-02 — 정책을 PRD 에 세움

운영자 지시 「문서에다가 적용좀해 정책또묻고 … 코드는이런데 정책이다르다 이러지말고」로 확정 정책을 §6.6 에 적었다. 15항 가운데 1~9 는 운영자 결정, 10~15 는 조율자가 위임(2026-11-01)으로 정한 것이다.

## 켜기 전에 §6.6 에 맞출 자리 — #975 (2026-11-02, 머지 전 head `6da31f3b`, 마이그레이션 · ADR 초안을 읽어 잰 값 · 돌려 보지는 않았다)

| §6.6 | #975 초안 | 맞출 일 |
| --- | --- | --- |
| 상세 궁합 요청은 72시간(5 · 6) | 7일(`match_request_ttl`) | 상세 요청의 기한 |
| 상세 궁합에 거절 단추 없음, 그냥 두면 만료(13) | 추천 표에 「상세의 거절」, 상태 `rejected`, 거절하면 양쪽 다 다시 못 청한다 | 거절 길 · 재요청 막음 |
| 동의 뒤 생성 실패로 글이 없으면 여덟 글자를 구매자에게서 거두고 새 동의(14) | 시도를 못 열면 되돌리지만, 연 뒤의 실패에 글자를 거두는 길은 diff 에서 찾지 못했다 | 실패 확정 때 거둠 |
| 정지로 닫힌 답 전 대화는 끝나고 해제 뒤 새로 시작(15) | ADR 「잠그지 않은 것」 — 풀리면 방이 다시 열리고 첫 말 제한이 이어진다 | 끝남 처리 |

답 전 거둠(11) · 답 전 상세 불가(12) · 첫 말 1건(3)은 같은 방향이다. 끝난 대화의 목록 · 사진 · 소개(10)는 재지 않았다.

## 2026-11-02 — D7 · 상세 궁합의 글 (#963)

D7 은 조율자가 위임으로 정했다 — 상세 궁합의 지시에서 「적어도 한 항목은 움직인다」를 지운다. 상수 · 함수까지 섰고 호출 지점 연결이 #975 뒤에 남았다 — [계약 §10](../../../text/detail-compat-contract.md).
