# G-130 기록

표의 줄: [간극 대장 「공개 출시」의 G-130](../../gaps.md#공개-출시)

정책의 원본은 PRD §6.6 이다. 여기는 경과와 그 절에 맞출 자리만 든다.

## 2026-11-02 — 정책을 PRD 에 세움

운영자 지시 「문서에다가 적용좀해 정책또묻고 … 코드는이런데 정책이다르다 이러지말고」로 확정 정책을 §6.6 에 적었다. 1~9 는 운영자 결정, 10~21 은 조율자 결정(운영자 위임)이다. 같은 날 운영자가 합의 방향 안의 세부 UX · 문구 · 한도 · 재시도를 맡겨, 조율자가 여덟 글자 · 동의 범위 · 다시 청하기 · 하루 10건(D4)을 고쳐 세웠다. 옛 위임의 「거두면 다시 못 연다」와 「실패 뒤 글자 거둠」은 걷혔다.

새 흐름의 여덟 글자는 ADR 0012 의 변경이다(15). 관계 해석에서 상대 글자를 유추할 위험은 남고 복원 불가를 보장하지 않는다. 직접 언급의 지시와 품질 검사는 #963 이 세웠고(아래), 부르는 곳은 아직 없다. 개인정보가 아니라는 것은 운영자 의견이고 법적 결론이 아니다. ADR 은 #975 가 쓰는데 그 초안은 아직 이 변경을 안 든다.

## #975 와 §6.6 의 대조 (2026-11-02)

앞 표의 네 자리(72시간 · 상세 거절 단추 없음 · 실패 때 글자 · 정지 해제 뒤)를 #975 가 맞춰 표를 지웠다. 실패 때 글자는 운영자 검토로 「새 흐름은 글자를 안 돌려준다」로 바뀌었다(ADR 0215). 대조는 그 PR 의 시험이 든다.

## 2026-11-02 — D7 · 상세 궁합의 글 (#963)

D7 은 조율자가 위임으로 정했다 — 상세 궁합의 지시에서 「적어도 한 항목은 움직인다」를 지운다. 상수 · 함수까지 섰고 호출 지점 연결이 #975 뒤에 남았다 — [계약 §10](../../../text/detail-compat-contract.md).

**글 안 직접 노출(15):** 조율자가 정했다 — 상세 글이 실제 기둥 두 글자를 직접 쓰면 막는다(`pillar-named-in-reading`, ADR 0163 추기). 기준은 운영자의 「상대 여덟 글자는 화면과 응답에 직접 공개하지 않습니다」이고 글도 든다. 있는 실패 길로 가 풀이권이 복원된다. 연결 전이라 아직 돌지 않는다.
