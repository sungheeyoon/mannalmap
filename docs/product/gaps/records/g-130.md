# G-130 기록

표의 줄: [간극 대장 「공개 출시」의 G-130](../../gaps.md#공개-출시)

정책의 원본은 PRD §6.6 이다. 여기는 경과와 그 절에 맞출 자리만 든다.

## 2026-11-02 — 정책을 PRD 에 세움

운영자 지시 「문서에다가 적용좀해 정책또묻고 … 코드는이런데 정책이다르다 이러지말고」로 확정 정책을 §6.6 에 적었다. 15항 가운데 1~9 는 운영자 결정, 10~15 는 조율자가 위임(2026-11-01)으로 정한 것이다.

## #975 와 §6.6 의 대조 (2026-11-02)

앞 표의 네 자리(72시간 · 상세 거절 단추 없음 · 실패 때 글자 · 정지 해제 뒤)를 #975 가 맞춰 표를 지웠다. 실패 때 글자는 운영자 검토로 「새 흐름은 글자를 안 돌려준다」로 바뀌었다(ADR 0215). 대조는 그 PR 의 시험이 든다.

## 2026-11-02 — 웹이 켜진 흐름을 그린다 (#964)

꺼진 동안 그대로다. 남은 틈 — 인연 탭의 「인연 기록 N」은 글이 선 대화를 안 센다(그 줄은 글 목록을 안 읽는다), 기록 화면은 책으로 센다. 「발견」 칸은 #963 이 정하기 전이라 결과에 안 선다.

## 2026-11-02 — 고지 문장 (#938)

동의 문장 · 켜는 날의 줄은 `docs/legal/match-talk-notice-draft.md`. 재어 본 어긋남 둘 — **참여 끄기가 상세 동의를 안 끝낸다**(`match_consent_holds` 가 안 본다. 끝내려면 DB 일이고, 그때 문장에 더한다). **§6.6 의 14 · 표 「생성이 실패할 때」는 「새 동의」인데 코드 · ADR 0215 는 같은 동의로 다시 만든다** — 고지는 코드 쪽으로 적었다.
