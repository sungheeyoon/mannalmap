# G-169 기록

## 2026-11-19 점검 · 고침 라운드가 남긴 손질

라운드의 사정은 `docs/notes/2026-11-19-agent-audit-round.md` 다. 항목마다 고치거나, 그대로 두는 까닭을 여기 적고 지운다. 목록이 비면 대장의 줄을 닫는다.
결정 거리(운영자에게 물을 것)는 그렇다고 적었다 — 나머지는 묻지 않고 고친다.

1. **대장 절 번호의 빈틈 시험** — `scripts/code-rules.test.ts` 의 「한 무리 파일 안에서 절 번호가 01 부터 끊기지 않는다」는 ADR 번호의 빈틈 시험(ADR 0254 가 걷음)과
   같은 꼴로, 나란히 도는 PR 이 번호를 미리 받으면 앞 번호 PR 이 들기 전까지 붉다. 운영자 답(2026-11-19)은 ADR 번호만이었다 — **결정 거리**.
2. **대장 「확인 전」 줄 판정이 엉성한 출처를 받는다**(#1177 독립 검토) — `nearest()` 가 자기 절 번호(`public-03` 줄의 `public-03`)와 코드 어디에나 있는 대문자 낱말(`URL`)을
   가까운 사례로 친다. 자기 절은 빼고, 상수는 정의된 이름(`const NAME`)만 받는다. 노트 판정의 `→ 「…」` 는 실제 절 이름일 때만 받는다.
3. **대장 시험의 머리 줄 거르기** — `^\| (---|자리) ` 가 자리 칸이 「자리」로 시작하는 진짜 줄도 건너뛴다(옛 구멍).
4. **ADR 0240 「머지된 ADR 에 추기를 달지 않는다」를 재는 잠금이 없다** — 0240(11-08) 뒤에도 ADR 0109 에 추기가 여섯 더 붙었다(#1134 · #1137 · #1148 · #1155 · #1168 둘).
   규칙 문장은 `docs/agents/domain.md` 「Writing an ADR」에 들었다(#1182). 「추기 머리 수는 늘지 않는다」 지문 잠금을 단다.
5. **낡은 머리 · 주석 둘** — ADR 0230 머리의 「ADR 0253 … 배포 전」(11-16 에 배포됐다) · `app/share/path.ts:3` 주석의 「앱 단추는 「공유 링크 복사」」(앱은 「공유하기」, 대장 home-13).
6. **대장의 섞인 절 다섯** — home-12 · home-14 · credits-14 · first-07 · matching-16 은 확정 줄과 「확인 전」 줄이 한 절에 섞였다(#1183). 나누려면 새 절 번호가 든다 —
   조율자가 번호를 미리 나눠 맡긴다.
7. **대장 all-04** — 「다시 받기 / 바꾸기」 줄의 「운영자 승인 2026-10-26」이 무엇을 승인했는지 기록이 없다 — 운영자 확인(#770 줄).
8. **출처끼리 어긋난 넷**(#1182 의 레퍼런스 모음을 만들며 찾음) — G-130 기록과 `docs/notes/2026-11-02-korean-app-flow-references.md` 의 확인 수준이 세 줄에서 다르다 ·
   ADR 0228 58 줄과 같은 ADR 의 표가 다르다 · `docs/product/copy-ledger/credits.md:208` 은 서비스 넷을 들고 「이 셋」이라 적었다 · ADR 0191 과 0192 가 리디 약관 링크를 다르게 말한다.
9. **한국 서비스 도움말 찾기** — 에이전트의 웹 검색은 한국 고객센터 · 도움말을 잘 못 찾는다(#1176 이 카카오 고객센터 글을 직접 열어 찾음).
   `docs/agents/code-rules/references.md` 의 찾는 차례에 「서비스 고객센터 · 도움말 페이지를 직접 연다」 한 줄.
10. **바이패스 줄의 범위**(ADR 0258) — 밤 라운드(`docs/agents/delegation/unattended.md`)와 herdr 흐름(`docs/agents/delegation/herdr.md`)의 머지에도 해당하는지,
    herdr 7.5 「정리 전에 묻는다」를 ADR 로 남길지 — 「해석 — 운영자 확인 전」으로 적혀 있다. **결정 거리**.
11. **바깥 검사가 아무것도 못 물어도 「맑다」**(#1178 · #1184 독립 검토) — `scripts/outside-red.mjs` 는 Maven 좌표를 하나도 못 물었거나(전부 「모른다」)
    찾은 좌표가 0 이어도 맑다고 하고 열린 이슈를 닫는다(`:101` · `:139`) — 그 파일 머리의 「안 잰 것을 맑다고 하지 않는다」와 어긋난다. 그 둘이면 이슈에 적는다.
    붉은 줄에 바깥의 오류 문구가 들면 날마다 글자가 달라 같은 판정에도 댓글이 쌓일 수 있다 — 판정 열쇠에서 문구를 뺀다.
12. **PR 본문 검사의 남은 꼴** — 봇 PR(Dependabot 보안 업데이트를 켜는 날)은 칸이 없어 붉다 — 켤 때 봇을 빼는 조건을 둔다 · `feat!:` 꼴 제목은 형식을 못 읽어
    문서 규칙을 건너뛴다(`scripts/pr-body.mjs:62`).
13. **대장 대조가 못 보는 자리** — `scripts/new-copy.mjs` 는 JSX 글자만 본다 — `src/lib/**` 의 문구 함수 · 상수(예: #1167 의 `notes.ts`)에 선 글자는 안 본다. `COPY_FILES` 를 넓힌다.
14. **러너 바깥의 남은 흔들림** — 11-11 은 apt 미러, 11-13 은 54322 포트 충돌이었다(ECR 은 CLI 가 4초 뒤 스스로 다시 받아 지나갔다). 브라우저 캐시는 apt 를 못 건너뛰고
    Playwright 컨테이너는 `authed` 의 스택과 맞지 않는다 — 다음에 나면 #1178 이 넣은 `ss` 줄이 포트를 쥔 것을 찍는다. 그 값으로 고친다.
