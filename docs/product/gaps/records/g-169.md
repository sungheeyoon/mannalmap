## 2026-11-19 점검 · 고침 라운드가 남긴 손질

라운드의 사정은 `docs/notes/2026-11-19-agent-audit-round.md` 다. 항목마다 고치거나, 그대로 두는 까닭을 여기 적고 지운다. 목록이 비면 대장의 줄을 닫는다.
결정 거리(운영자에게 물을 것)는 그렇다고 적었다 — 나머지는 묻지 않고 고친다.

4. **러너 바깥의 남은 흔들림** — 11-11 은 apt 미러, 11-13 은 54322 포트 충돌이었다(ECR 은 CLI 가 4초 뒤 스스로 다시 받아 지나갔다). 브라우저 캐시는 apt 를 못 건너뛰고
    Playwright 컨테이너는 `authed` 의 스택과 맞지 않는다 — 다음에 나면 #1178 이 넣은 `ss` 줄이 포트를 쥔 것을 찍는다. 그 값으로 고친다.
    **2026-11-19 밤에 apt 쪽이 다시 났다** — #1196 의 verify [run 44523228732](https://github.com/sungheeyoon/mannalmap/actions/runs/44523228732)(21:25 ~ 21:28(서울), 러너 `ubuntu-26.04` 20261116.88)의
    e2e 차선 여섯(anon · authed signed-in:mobile · chat:mobile · live · match:mobile · match:desktop)이 `npx playwright install --with-deps chromium` 에서 섰다.
    `apt-get update` 의 목록은 `/etc/apt/apt-mirrors.txt` 의 EC2 미러(`us-east-2.ec2.archive.ubuntu.com`)에서 잘 받았는데, 글꼴 패키지 아홉은
    `https://security.ubuntu.com/ubuntu` 로 가서 하나에 약 15초씩 `Could not wait for server fd - select (11: Resource temporarily unavailable)`
    (IP 91.189.91.82 · 185.125.190.83)로 끊겼다. 왜 EC2 미러가 아니라 security 로 갔는지는 로그에 없다(미러 목록의 다음 자리로 넘어간 것으로 보이나 확인 전).
    apt 는 이미 다시 받기를 하므로(`Acquire::Retries`, 기본 3) 그 값을 올리는 것은 근거가 모자라 넣지 않았다. 54322 는 아직 다시 나지 않았다
    — #1178(2026-11-19 18:40(서울) 머지) 뒤 이 run 전까지 verify 20 번에서 바깥 탓 실패는 없었다. 다음에 나면 그 잡에서 `cat /etc/apt/apt-mirrors.txt` 의 차례를 보고 고친다.
