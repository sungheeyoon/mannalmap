## 2026-10-31 — 앱 라운드를 끝맺을 때의 사실

화면 표와 운영자 결정은 `docs/notes/2026-10-30-expo-app-round.md` 가 든다. 전수 측정은 안드로이드 에뮬레이터(API 37 · Expo Go)와 가짜 서버였다(#927, 차례는 `docs/agents/delegation/local-env.md` 「앱을 네이티브로 재기」).

### 남은 것

- **실제 DB 로 앱 호출 재기** — 로컬 스택에 docker 가 필요하다. RLS 를 앱 세션으로 잰 적이 없다.
- **구글 로그인** · **iOS** · **개발 빌드 실기기**
- **실제 S3 올리기** — 앱의 `s3` 길은 저장소를 켠 적이 없어 안 돌았다(G-120 · G-124 · G-125).
- **푸시** — G-71 이 `보류` 다. 권하지 않는다, 운영자가 다시 꺼낸다.
- **인앱결제**(ADR 0212, #937) · **스토어**
- **`/api/mobile/**` 운영 배포** — 운영에 나가기 전에는 실제 앱이 이 문에 못 닿는다.

### 웹과 다르게 둔 자리

고칠 일로 재지 않으면 틀린 것으로 읽힌다 — 알고 둔 것이다.

- 내 사주 등록 폼의 여백
- `/help` 「서비스 소개」 단추의 폭
- 설정 메뉴 시트
- 입력 폼과 궁합 지도의 안쪽 값
- 경고 안내는 탭 첫 화면에만 선다

### 낮은 일

- 앱의 인연 입구의 성인 확인 — 스위치가 꺼진 채 안내와 복귀가 섰다(ADR 0214, #947). 단계 표 `src/lib/brand/guide.ts` 의 줄은 켜는 PR 이 더한다 — 꺼진 앱의 글자를 안 바꾸려고 뒀다.

- 화면 도중 세션이 끊겨 각 화면이 `router.replace('/')` 로 보내는 자리는 목적지를 안 든다(ADR 0213 「잠그지 않은 것」). 앱을 다시 앞으로 가져오면 관문이 잡는다.

- 홈이 스택에 여러 번 쌓이면 `PUT /api/mobile/me/participation` 이 그만큼 나간다(`mobile/src/app/me/(tabs)/index.tsx:30`). 멱등이라 값은 안 틀린다.

## 로컬 실제 DB 로 잰 것 (2026-10-31)

`scripts/check-mobile.mjs` 가 잰다. 찾은 것:

- **고쳤다** — 끊긴 세션(로그아웃 · 세션 만료)의 토큰에 앱의 문이 401 대신 503 을 답했다. 라이브러리가 `session_not_found` 를 `AuthApiError` 가 아닌 오류로 바꿔 던져서다. 앱이 다시 로그인으로 못 가고 다시 시도만 보였다.
- **DB 의 틈 — 닫았다(`20270104090000`, #941)** — 베타 종료 뒤에도 `create_managed_person` 이 사람을 만들었다. `status` 만 보고 종료를 안 봤고, ADR 0211 이 적은 `edit_person_input` 의 틈과 같은 꼴이었다. 이제 둘 다 `create_self_person` 과 같은 문장으로 거절한다.
- **DB 의 틈 — 닫았다(`20270104090000`, #941)** — 가입을 안 마친 세션이 `save_my_profile` · `add_my_photo` 를 바로 부를 수 있었다. 이제 두 문과 `lock_my_photos` 를 지나는 사진의 문 전부가 「가입을 먼저 끝내 주세요.」로 거절한다. 재는 자리는 `supabase/tests/99_signup_and_end_stop_the_writes.test.sql` · `scripts/check-mobile.mjs`.

안 잰 것: 실제 S3 올리기 · 모델의 성공 · 실제 경고 줄(`my_warning_notice`) · 실제 주문 줄(`my_reading_orders`) · 화면 위의 해석. 칸 이름까지만 쟀다.
