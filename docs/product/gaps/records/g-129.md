# G-129 기록

표의 줄: [간극 대장 「공개 출시」의 G-129](../../gaps.md#공개-출시)

## 물음 (2026-11-02, ADR 0212)

영수증 검증 · 환불 통지를 스토어와 직접 잇나, 중개 서비스(RevenueCat 등)를 두나. 두면 처리방침의 받는 곳 줄이 는다(#938).

## 저장소의 기존 정책

없다. 지급은 서버만 한다는 것은 정했다 — 주문을 승인으로 만드는 것은 서버뿐이다(ADR 0106).

## 한국 출시 서비스 사례 (2026-11-02 확인)

**어느 쪽을 골랐다고 밝힌 한국 출시 서비스를 찾지 못했다.** 찾은 것은 한국어 일반 설명뿐이다 — 직접 지으면 서버 검증 · 영수증 · 환불 처리 비용이 든다는 글(<https://velog.io/@skydoves/revenuecat-app-business>). 사례로 세지 않는다.
