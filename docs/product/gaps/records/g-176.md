원문으로 다시 읽고, 이기는 쪽을 원본(ADR · 원본 문서 · 스크립트)이 이미 말하는 자리를 맞췄다. 남은 셋은 에이전트가 무엇을 해도 되는지를
바꾸거나 ADR 본문을 고치는 자리라 운영자의 답을 기다린다.

## 남은 것 — 운영자에게 묻는다

### ② 원격 백필은 누가 돌리나

- ADR 0093 「배포만 묻는다」(2026-11-07)는 `ask` 에서 뺀 「실호출 환경변수 다섯」에 `BACKFILL_CHART=1` · `BACKFILL_READING_CHART=1` 을 넣고,
  「실호출은 운영자가 직접 돌린다」고 한다
- 실호출은 토큰이 나가는 모델 부름이다(`AGENTS.md` 「멈출 선」 · `permissions.md` 「권한 등급」의 등급 3 · `docs/agents/test-map/live.md` 「잠긴 시험 넷」).
  백필은 모델을 부르지 않는다 — 운영 DB 의 출생정보를 읽어 명식을 다시 쓴다(`src/lib/input/backfill-chart.live.test.ts` 머리 주석)
- `docs/roles/reading.md` 「지킬 것」은 백필도 운영자에게 넘긴다고 하고 원본으로 `permissions.md` 를 가리키는데, 그 문서에는 백필이 없다.
  그 문서로는 운영 DB 쓰기는 「묻지 않고 하고 값을 적는다」이고 출생정보를 읽는 SQL 은 에이전트가 보내지 않는다 — 백필은 두 줄에 함께 걸린다
- 두 백필의 원격 읽기는 `npx supabase db query --linked` 를 바로 불러 `db:remote` 의 잠금과 접속기록을 거치지 않는다

- **안 A — 운영자가 돌린다(권고, 지금 `reading.md` 대로).** `permissions.md` 등급 3 줄에 「원격 백필(`BACKFILL_*` + `BACKFILL_TARGET=remote`)도
  운영자가 돌린다 — 출생정보를 읽는다(ADR 0105)」를 더하고 `live.md` 표의 두 줄에도 적는다. ADR 0093 은 고치지 않는다
- **안 B — 에이전트가 돌리고 채운 행 수를 적는다.** 토큰이 안 나가고 출생정보를 찍지 않으니 운영 개인정보 문단에 예외로 적고 `reading.md` 에서
  백필을 뺀다. 그 전에 두 백필의 원격 읽기를 `db:remote` 로 옮기는 코드 PR 이 필요하다

### ③ 신고 id 로 적는 검토 기록을 에이전트도 보내나

- `docs/ops/runbook/access.md` 「개인정보는 화면으로만」의 「보통」 줄은 「신고 id 로 적는 검토 기록」을 건수 · 집계와 함께 두고 「사람이든 에이전트든
  `db:remote`」라 한다
- `permissions.md` 의 보내도 되는 원격 질의 목록에는 검토 기록이 없다. 검토 함수(`review_report`)는 제재 대상 계정의 UUID 를 받고, 이용 정지를 고르면
  그 계정을 함께 정지한다(ADR 0107 결정 4)
- ADR 0107 결정 3 은 「운영자가 CLI 로 부른다」고 한다 — 화면에서 읽고 판단한 뒤 적는다(`docs/ops/runbook/moderation.md` 「신고와 차단」)

- **안 A — 운영자만 보낸다(권고).** `access.md` 「보통」 줄의 검토 기록에 「운영자가 보낸다(ADR 0107)」를 달고 `permissions.md` 는 그대로 둔다
- **안 B — 운영자가 판단을 불러 주면 에이전트도 보낸다.** `permissions.md` 목록에 「신고 id 로 적는 검토 기록」을 더한다

### ④ ADR 0089 의 「changelog 의 날짜」

- ADR 0089 「옮긴 절을 가리키던 자리」는 코드 주석이 PRD 의 절 번호 대신 「changelog 의 날짜나 대장의 `G-nn`」을 쓴다고 했다
- `comments.md` 「주석과 ADR 참조」는 제품 코드 주석의 날짜를 시험으로 막는다(#1157, `scripts/dated-comments.json`). 코드를 어떻게 적나의 원본은
  `CODING_STANDARDS.md` 와 시험이다(`docs/start.md` 「원본 — 무엇이 무엇을 답하나」)
- 머지된 ADR 본문은 다시 쓰지 않는다 — 예외는 정책이 그대로이고 문장이 코드와 다를 때의 짧은 정정 절이다(`docs/agents/domain.md` 「Writing an ADR」)

- **안 A — ADR 0089 는 그날의 기록으로 둔다(권고).** 지금 규칙은 `comments.md` 에 있고 시험이 확인한다. 이 자리는 그대로 닫는다
- **안 B — ADR 0089 에 짧은 정정 절을 단다.** 「주석의 날짜는 #1157 부터 시험이 막는다 — 대장의 `G-nn` 이나 ADR 을 쓴다」
