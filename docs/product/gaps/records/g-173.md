## 2026-11-20 새벽 회고가 남긴 손질

라운드의 사정은 `docs/notes/2026-11-20-deploy-and-shots-round.md` 다. 회고(#770 의 2026-11-19 인계 댓글 「회고」 절) 여덟 가운데 1 · 2 는
#1204 · #1205 로 적용했고, 아래 여섯(회고 3 ~ 8)이 남았다. 항목마다 고치거나, 그대로 두는 까닭을 여기 적고 지운다. 목록이 비면 대장의 줄을 닫는다.
결정 거리(운영자에게 물을 것)는 그렇다고 적었다 — 나머지는 묻지 않고 고친다.

1. **Next 의 에이전트 멈춤이 다음 권고 때 또 생긴다**(회고 3) — 16.4.2 의 기본 `experimental.agentUpgrade: 'security'` 가 에이전트가 돌린 `next dev` · `next build` 를
   멈췄다(#1203 이 16.4.6 으로 올려 없앰, 함정 줄은 `docs/agents/delegation/local-env.md`). CI 감사 문턱은 high 라 moderate 권고가 다시 나면 CI 는 통과하는 채 에이전트만 멈춘다.
   길은 둘 — `next.config.ts` 에 `experimental.agentUpgrade: false`(**결정 거리** — Next 가 권하는 보안 안내를 끄는 설정이라 운영자에게 묻는다) 또는
   `scripts/session-status.mjs` 가 `npm audit` 의 `next` 줄을 찍어 세션을 열 때 안다(묻지 않고 해도 된다).
2. **Docker 꺼짐을 화면 라운드 한가운데서 안다**(회고 4) — `scripts/session-status.mjs` 에 Docker 켜짐 / 꺼짐 한 줄.
3. **지운 아티팩트 링크가 문서에 남는다**(회고 5) — 운영자가 아티팩트를 두 번 다 지웠고 그때마다 링크가 죽었다(#1173 의 17 · 2026-11-20 의 6).
   규칙 「아티팩트 주소는 저장소 문서에 적지 않는다」를 원본(`docs/agents/delegation/done.md` 「끝났다는 것」의 그림 문단)에 두고,
   `scripts/code-rules.test.ts` 가 `claude.ai/(code/)?artifact/` 링크를 잠근다(「지움」 표기는 통과). 남아 있던 링크 여섯은 이 줄을 연 PR 이 「아티팩트(2026-11-20 지움)」로 바꿨다.
4. **세션 끝 라운드 노트가 빠진다**(회고 6) — 11-19 밤 PR 열하나 뒤 노트가 없었다. `scripts/session-status.mjs` 가 「마지막 라운드 노트 뒤 머지된 PR 수」를 찍는다.
5. **PR 칸 검사를 CI 가 처음 잡는다**(회고 7) — PR 제목 범위의 빈칸(#1196) · 「결정 여부」 줄 빠짐(#1193). `scripts/pr-title.mjs` · `scripts/pr-body.mjs` 를
   PR 열기 전에 함께 돌리는 `package.json` 스크립트 하나(이름은 `pr:check` 꼴 — 아직 없다).
6. **작은 마찰 넷**(회고 8) —
   `.pr-body.tmp.md` 가 남은 워크트리를 정리가 건너뜀(→ `.gitignore`) ·
   `npm install <패키지>@<버전>` 이 상관없는 잠금 줄을 바꿈(→ 잠금 꾸러미 비교를 `docs/ops/runbook/security.md` 「운영 의존성 취약점」의 올리는 걸음에) ·
   `scripts/checkout-hint.mjs` 가 `cd $변수` 를 못 따라가 워크트리 커밋에 헛경고(→ 펼 수 없는 `cd` 는 조용히) ·
   병렬 PR 넷이 같은 간극 기록 파일을 고쳐 충돌(→ `docs/agents/delegation/parallel.md` 「나란히 맡길 때」의 중앙 문서에 `docs/product/gaps/records/`).
