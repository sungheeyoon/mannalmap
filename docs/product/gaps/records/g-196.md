# G-196 기록

표의 줄: [간극 대장 「공개 출시」의 G-196](../../gaps.md#공개-출시)

2026-11-28 조율자 세션의 풀이 모델 조사(아티팩트(2026-11-28))다. 운영자 말(그대로): 「한글을 잘하는 모델로 바꿔야 될 거 같은데 한국인들 유명한 사람들의
전언, 코드팩토리 등 에이전트를 많이 써 본 사람이 말하는 한국어 잘하는 모델을 일단 추려서 추천해 주고」. **모델을 직접 부르지 않았다** — 증언과 공식 값뿐이고,
어느 모델이 우리 프롬프트에서 나은지는 실호출로만 답이 난다.

## 운영자 결정 — 같은 급의 새 세대로 옮기고 윗급은 미뤘다(2026-11-28)

후보의 값을 보고: 「비용이 너무 올라가네 흠 그건 너무 차이나는데」. 조율자가 한 급 위(`gpt-6.1-terra`, 약 4.5배)를 권하면서 같은 급의 새 세대(`gpt-6-luna`, 절반 값)도
함께 견주자고 하자: 「gpt-6-luna 로 바꾸자 그럼 더 싸다며 절반이고 더 좋고」.

- **옮긴 것** — 풀이 모델이 `gpt-6-luna` 다(이 기록을 고친 PR 이 `app/me/reading/generation.ts` 의 `GENERATION` 을 옮겼다). 값은 입력 0.10 · 캐시 입력 0.01 · 출력 0.50
  달러 / 100만 토큰(<https://developers.openai.com/api/docs/pricing> · <https://developers.openai.com/api/docs/models/gpt-6-luna>, 2026-11-28 확인). 모델 페이지는
  「GPT-6 Luna is our most efficient model for focused, high-volume tasks.」라 적고 Responses · 구조화 출력을 지원한다고 적는다. 추론 세기의 값과 기본값은 옛 모델과 같다
  (`none` · `low` · `medium`(기본) · `high` · `xhigh` · `max`). 옮김 안내서(「Using GPT-6」)의 요구 — 추론 세기가 `none` 이 아니면 `temperature` · `top_p` 를 뺀다 — 는
  우리가 그 값을 안 보내 걸리지 않는다. 회사가 같아 처리방침 · 약관은 그대로다.
- **확인 전** — 새 모델의 글이 더 나은지. 운영자의 「더 좋고」는 조율자가 확인해 준 말이 아니다(조율자는 「같거나 나으면」이라고 했다). 옮긴 PR 의 「사람이 할 걸음」의
  실호출 한 번으로 본다.
- **미룬 것** — 윗급(`gpt-6.1-terra` · `gpt-6.2-sol`)과 다른 회사 모델. 운영자가 다시 꺼낼 때까지 권하지 않는다. 아래는 꺼낼 때의 출발점이다.

## 옮기기 전의 모델

2026-11-28 까지 운영 풀이는 `gpt-5.6-luna` 를 OpenAI Responses API 로 불렀다(`app/me/reading/generation.ts` 의 `GENERATION`). OpenAI 모델 페이지의 원문(조사 에이전트가 읽음 ·
수준 B): 「GPT-5.6 Luna is designed for cost-sensitive, high-volume workloads.」 · 「It roughly corresponds to the nano model tier used in earlier GPT-5 families.」
(<https://developers.openai.com/api/docs/models/gpt-5.6-luna.md>). 값은 입력 0.20 · 출력 1.20 달러 / 100만 토큰이었다(지금 모델의 값은 `docs/ops/runbook/ai.md` 「비용 — 토큰 × 공식 단가」).

## 값과 순위

값은 100만 토큰당 달러(입력 / 출력), 각 회사의 공식 값 페이지를 조사 에이전트가 2026-11-28 에 확인했다 — <https://developers.openai.com/api/docs/pricing> ·
<https://platform.claude.com/docs/en/about-claude/pricing> · <https://aistudio.google.com/docs/pricing>. 풀이 한 편은 입력 8만 · 출력 1만 토큰(추론 포함) · 캐시
없음으로 어림했다 — 실제 토큰 수는 잰 적이 없다(프롬프트 약 9만 9천 자에서 어림).

| 모델 | 입력 / 출력 | 풀이 한 편 어림 | 왜 |
| --- | --- | --- | --- |
| `gpt-6-luna`(2026-11-28 부터) | 0.10 / 0.50 | 0.013 달러 | 같은 급의 새 세대 — 값 절반 |
| `gpt-5.6-luna`(옮기기 전) | 0.20 / 1.20 | 0.03 달러 | 가장 싼 급 — 기준 |
| `gpt-6.2-sol` | 2 / 10 | 0.26 달러 | 코드팩토리가 한국어 글에 쓰는 계열. 같은 회사라 모델 이름 한 줄 |
| Claude Sonnet 5.5 | 2 / 10 | 0.26 ~ 0.35 달러(같은 글이 토큰으로 더 잡힐 수 있다) | 「앤트로픽 모델 중 한국어는 제일 좋다」 |
| Gemini 4 Hydrogen | 1.5 / 7.5 | 0.20 달러 | 「GPT 를 빼면 제일 잘 읽힌다」 |
| Claude Opus 5.5(기준점) | 4 / 20 | 0.52 ~ 0.70 달러 | 한국어 순위 1위. 코드팩토리는 Sonnet 보다 번역한 글 같다고 했다 |
| `gpt-6.1-terra` | 1 / 5 | 0.13 달러 | 같은 회사의 가운데 급 |

- 풀이권 한 장은 묶음에 따라 2,950 ~ 4,900원이다(`src/lib/reading/bundle.ts`). 2 / 10 달러 급이면 풀이 한 편의 모델 값이 옮기기 전의 약 아홉 배다.
- Gemini 4 Argon(2 / 10)은 2026-12-01 부터 4 / 20 이 된다고 값 페이지가 적어 후보에서 뺐다.
- 사람들이 고른 한국어 순위(Arena 한국어 텍스트, 2026-11-22, <https://arena.ai/leaderboard/text/korean> · 조사 에이전트가 읽음) — 1 Claude Opus 5.5(1502) · 2 Claude
  Fable 5(1490) · 3 Gemini 4 Argon(1489) · 4 Claude Fable 5.1(1484) · 5 Claude Opus 5(1482) · 13 GPT-6.1 Sol(1473) · 14 GPT-5.6 Sol(1463). Sonnet 5.5 와 luna 는
  15위 밖이고 점수를 못 봤다. 이 순위는 글의 자연스러움만이 아니라 답의 쓸모 전체를 잰다 — 「순위는 Opus, 글맛은 Sonnet」이라는 엇갈림이 남는다.

## 견주는 법(권고)

같은 사주 셋(개인 풀이 둘 · 궁합풀이 하나)을 지금 것 · `gpt-6.1-terra` · `gpt-6.2-sol` · Claude Sonnet 5.5 · Gemini 4 Hydrogen · Claude Opus 5.5 로 한 번씩 받는다(어림 5달러
안쪽). 이름을 가리고 읽는다 — 가린 묶음을 만드는 도구가 있다(`src/lab/reading/match-input-eval.ts` 의 `blindPacket`, 프롬프트 견주기용이라 모델 견주기에 맞게
고쳐 쓴다). 추론 세기는 낮은 쪽부터 견준다(위 증언). `gpt-6.2-sol` 이 충분하면 거기서 멈춘다. 실호출은 운영자가 돌린다.

## 회사를 바꾸면 따라 바뀌는 것

- **처리방침** — 「풀이를 만들 때 밖으로 나가는 것」 절이 「외부 인공지능 서비스(OpenAI, 미국)가 씁니다」라고 적고, 처리위탁과 국외 이전의 받는 곳도 OpenAI 다
  (`src/lib/consent/notice.ts`). 회사가 바뀌면 내용 개정이고, 기존 회원에게 다시 확인을 받을지는 그때 따로 정한다.
- **약관은 그대로다** — 제6조③ 은 「풀이 글은 생성형 인공지능이 만듭니다」라고만 적고 회사 이름이 없다(`src/lib/brand/terms.ts`).
- **코드** — 부르는 길 · 답의 모양(구조화 출력) · 추론 세기 · 기다리는 시간 · 토큰 세는 법(`app/me/reading/model.ts`). OpenAI 와 Anthropic 의 후보는 각 회사 문서의
  지원 목록에서 구조화 출력을 확인했고 Gemini 는 모델 이름까지는 확인하지 못했다(조사 에이전트 · 수준 B).
- **비용 한도와 운영 문서** — 한도와 비용 셈이 지금 모델의 값으로 적혀 있다(`docs/ops/runbook/ai.md` 「AI 비용 한도 — **안쪽 벽과 바깥 벽** (ADR 0039)」).
- 로그인 전 첫 화면의 짧은 문단은 싼 모델에 그대로 둘 수 있다.

## 못 확인한 것

`gpt-6.1-terra` 의 구조화 출력 · 풀이 한 편의 실제 토큰 수.
