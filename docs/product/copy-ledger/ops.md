# 화면 문구 대장 — 운영 화면 · 작업대

화면: `/ops/**` · `/me/reading/inspect`.

규칙 · 여러 화면에 걸친 줄 · 무리 색인은 대장의 머리 `docs/product/copy-ledger.md` 가 든다 — 여기는 이 무리 화면의 확정 문구만이다.
새 절의 번호는 `ops-01` 부터다. 한 절의 줄이 여러 무리에 걸치면 머리말은 한
곳에 두고 다른 무리에는 그 무리의 줄만 둔다.

아직 이 무리만의 확정 문구가 없다 — 운영자 전용 설명은 결정이 아니다(`docs/roles/ui.md` 「하지 않는 것 · 묻는 것」).
