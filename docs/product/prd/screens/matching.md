# 사주 서비스 PRD — 화면: 인연 · 채팅 · 소식

색인은 `docs/prd.md` 다. 이 파일은 「3. 화면」(`docs/product/prd/screens.md`)의 한 무리다 — 모든 화면에 걸리는 규칙(§3 머리의 규칙 ·
§3.2 버튼은 동사로 갈린다)과 무리 색인은 그 파일에 있다(2026-10-10 에 화면 표와 §3.0 · §3.1 을 무리로 나눴다, ADR 0162). 이 화면들의 확정 문구는 `docs/product/copy-ledger/matching.md`. 덱 · 카드 · 요청 · 소식 · 차단과 신고의 동작은 §6(`docs/product/prd/matching.md`), 대화방은 §7.1(`docs/product/prd/chat.md`)이 든다.

### 화면 표 — 인연 · 채팅 · 소식

| 화면 | 주소 | 어디서 가나 | 역할 |
| --- | --- | --- | --- |
| 인연 소개(앱만) | `/matching-intro` | 로그인 전 첫 결과의 「인연은 어떻게 찾나요?」(앱 입구에서는 걷었다 — ADR 0226) | 로그인 없이 여는 화면. **회원을 안 읽고 실제 회원이 없다** — 「예시」 카드 한 장(사진 · 닉네임 · 활동 표시 · 「예상 궁합 N점」 · 누를 자리 없음)과 추천 이유 → 대화 시작 → 상세 궁합의 실제 규칙(#965, ADR 0221). 「인연 시작하기」는 `/auth?next=/me/matching` 이고 참여는 그 뒤의 지금 동작 그대로다 |
| 매칭 | `/me/matching` | 메뉴의 **인연** · 홈의 오늘의 인연 진입 | **폰 한 화면이다**(ADR 0130 「2026-09-29 u2」). 사진 중심 카드로 실제 후보를 탐색하고(넘기는 일은 단추가 한다) 「대화 시작」으로 대화를 여는 덱(시작하면 그 대화방 `/me/chat/[matchId]` 로 간다, §6.2) → **「인연 기록 N」 한 줄**(0 이면 안 선다 → `/me/matching/history`). 받은 요청 띠는 없다 — 받은 대화는 채팅 목록에 선다(ADR 0221). 넓은 화면은 덱 왼쪽에 사람, 오른쪽에 「내 궤도로 다가오는 인연」 지도. 지나친 인연은 같은 화면의 두 번째 보기다 (§6.1.1) |
| 성인 확인 안내(앱 · 웹) | `/me/matching/adult-check` | 스위치가 켜졌고 미확인인 사람이 인연 · 요청 · 채팅 주소에 오면 앱은 껍데기가, 웹은 관문(`proxy.ts`)이 갈아 끼운다. 확인이 곧 공개 시점이라는 줄이 선다. 업체가 정해지기 전이라 단추가 없다. **지금은 꺼져 있어 아무도 안 온다** | 끝나면 온 주소로 돌아간다(ADR 0214) |
| 인연 기록 | `/me/matching/history` | 인연 탭의 「인연 기록 N」 한 줄 | 인연 탭 불. **상세 궁합** 전부(책장 표지 · 동의 직후 만드는 중인 것은 편지, 누르면 `/me/match/[id]?from=history`) → **「끝난 대화」**(답 전에 끝난 대화 — 닉네임과 「신고」, 「대화가 끝난 뒤 90일까지 신고할 수 있어요.」, 사진 · 소개 · 끝난 까닭 없음, §6.2) · 차단한 사람 수. 따로 읽고 못 읽은 쪽만 까닭 한 줄. 머리는 상단 바 — ← 아이콘(인연 탭) 줄 아래 「인연 기록」(2026-10-24 · 10-26) |
| 채팅 | `/me/chat` · `/me/chat/[matchId]` | 메뉴 · 카드의 「대화 시작」 · 인연 궁합의 「채팅」 · 상세 궁합 요청 소식 | 대화를 시작한 상대와의 대화방 목록과 방 안(§7.1). 받은 대화가 목록에 서고 답하지 않은 대화는 「답하지 않은 대화」로 접힌다. 답 전 보낸 쪽에는 「대화 취소」가 선다(§6.2). 방 머리의 「상세 궁합」과 머리 아래 공용 카드가 상세 궁합의 상태를 들고, 완성이면 인연 궁합 화면으로 간다(§6.3) |
| 소식 | `/me/requests` | 머리글의 **종**(안 읽은 수) | 알림(최근 순)만. 상세 궁합 요청의 소식은 그 대화방으로, 풀이 소식은 그 풀이로 간다 (ADR 0130 · 0157 · 0221). 결과 화면(한 사람 풀이 · 궁합 결과 · 인연 궁합 결과)을 열어 그 글이 보이면 그 풀이의 완성 소식은 읽음이 되고, 상세 궁합의 완성 소식은 두 사람 다 받는다 (§6.4, ADR 0157 「2026-10-10 덧」). 아래의 「소식은 앱 안에서만 볼 수 있어요 …」 안내 줄은 운영자 결정으로 걷음(2026-10-26) |
| 인연 궁합 결과 | `/me/match/[id]` · 풀이 보관함에서 열면 `/me/readings/match/[id]`(같은 화면이 책장 옆 칸에 선다, ADR 0134) | **풀이 목록** · 대화방의 「상세 궁합」 | 받은 사람의 동의로 만든 두 사람의 상세 궁합. 머리는 한 줄 — ← (아이콘, 온 곳) · 상대 얼굴(누르면 상대 프로필 시트) · 제목 「{상대} 님」과 작은 「궁합 결과」(닫힌 결과는 「궁합 결과」, 대장 matching-01). 한 문장 결론 · 점수 · 풀이 본문 차례로 서고 여덟 글자 · 두 명식은 없다(§6.3). 아직 없으면 「아직 상세 궁합이 없어요. 대화방에서 열 수 있어요.」. 방으로 가는 **「채팅」은 머리의 제목 옆**(방에서 왔으면 ← 가 그 방이라 안 선다), 그 오른쪽에 신고 · 차단 **「⋯」**(ADR 0158) |
