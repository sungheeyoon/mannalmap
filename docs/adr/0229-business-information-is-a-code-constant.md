# 사업자 정보는 코드 상수 한 벌이고, 웹과 앱이 같은 값을 읽는다

> **운영자 결정 2026-11-06**(조율자 세션). 「사업자 정보는 환경변수가 아니라 상수로 둔다 — 상호 · 대표자 · 사업자등록번호 · 사업장
> 주소 · 대표전화 · 통신판매업 신고번호 전부.」 운영자는 저장소가 공개이고 집 주소와 대표자 이름이 git 기록에 남는 것을 알고 골랐다.
> 이 결정이 대체하는 것 — ADR 0172 의 「정한 것」 2(값은 환경변수), ADR 0151 「정한 것」 2 의 「집 주소는 저장소에 적지 않는다」,
> ADR 0152 「정한 것」 2 가운데 사업장 주소(상수 파일 한 곳만 비킨다).

## 까닭

- **환경변수는 찾을 수도 맞출 수도 없었다.** 같은 값이 Vercel(`BUSINESS_*` 여덟)과 EAS(`EXPO_PUBLIC_BUSINESS_*` 여덟)에 따로 살았고,
  저장소에는 이름만 있어 지금 무엇이 나가는지 운영 화면을 열어야 알았다. 앱의 EAS 값은 비어 있어 앱의 약관 · 환불정책에서 그 줄이
  안 섰다(`docs/ops/runbook/mobile-release.md`, 2026-11-06 전).
- **값은 법이 공개하라는 것이다.** 전자상거래법 제10조의 표시라 운영 바닥글 · `/terms` · `/refund` 에 이미 모두에게 서 있다. 저장소에
  적어도 새로 드러나는 것이 없다.

## 정한 것

1. **값은 `src/lib/brand/business.ts` 의 `BUSINESS` 상수다.** 화면은 고른 값 `BUSINESS_INFO`(이메일은 `SUPPORT_EMAIL`)를 읽는다 —
   웹(뿌리 레이아웃의 바닥글 · `/terms` · `/refund` · 결제 · 결제 내역)과 앱(`mobile/src/app/policies.tsx` · `terms.tsx` · `refund.tsx`,
   `@brand/business`)이 같은 한 벌이다. 환경변수를 읽던 `app/business-info.ts` · `mobile/src/info/business.ts` 를 걷었고,
   `scripts/secret-env.mjs` 의 `BUSINESS_*` 여덟과 `mobile/.env.example` 의 `EXPO_PUBLIC_BUSINESS_*` 여덟을 지웠다.
2. **값은 운영 화면의 공개 표시에서 옮겼다(2026-11-06, 운영 주소(`docs/ops/runbook/domain.md` 맨 위)의 바닥글 · `/terms` · `/refund`).** 운영 화면에 없는 대표전화는
   빈 문자열로 두고 D-U-N-S 날 발급받으면 넣는다. 통신판매업 신고기관(`MAIL_ORDER_AUTHORITY`, Google Play 「개발자 연락처」에 적는 값)도
   운영자가 알려주면 넣는다.
3. **사업장 주소 전체를 적는 자리는 이 상수 파일 하나다.** 공개 저장소의 개인정보 시험(`scripts/code-rules.test.ts`, ADR 0152)은 동 · 호
   꼴만 이 파일에서 비키고, 휴대폰 · 주민번호 꼴은 여기서도 잰다. 문서 · 노트는 주소를 옮겨 적지 않고 상수를 가리킨다.
4. **빈 칸은 그대로 줄째 안 선다.** `businessInfoFrom` 의 고르기(자리표시 · 꼴이 틀린 값은 빈 값)는 그대로이고, 시험이 상수가 고르는
   동안 하나도 빠지지 않는지와 사업자등록번호의 `123-45-67890` 꼴 · 공개 페이지 주소가 그 번호를 가리키는지를 잰다
   (`src/lib/brand/business.test.ts`).

## 치르는 값

- 주소 · 대표자 이름이 공개 저장소의 기록에 남는다. 나중에 사업장을 옮겨도 옛 값은 기록에서 지워지지 않는다.
- 값을 바꾸려면 코드 PR 과 배포다 — 콘솔에서 고치고 다시 배포하던 것과 걸음 수는 같다.
- Vercel · EAS 에 남은 `BUSINESS_*` · `EXPO_PUBLIC_BUSINESS_*` 는 아무도 안 읽는다. 지우는 것은 운영자의 콘솔 걸음이다(#770 B).
