# 가입은 만 14세 이상이고, 법정대리인 동의를 받는 길은 만들지 않는다

> 정한 날 2026-11-06 — 운영자 지시 「있는 정책 → 한국 서비스 사례로 정한다」에 따라 조율자 세션이 정했다. 이 ADR 은 그 결정을 옮겨 적은
> 것이고 새로 정한 것이 없다. 처음 적힌 자리는 `docs/ops/play-listing.md` 「만 14세 이상 가입 — 정한 것」이다(Play 타겟층 답의 근거).
>
> 이 결정이 대체하는 것 — ADR 0024(일부 — 「남는 것」의 「만 14세 미만은 법정대리인 동의가 필요하다 … 공개 전환 때 다시 볼 자리다」).

결정 점검표의 「누가 무엇을 할 수 있는가」(가입의 문)에 걸린다.

## 정한 것

1. **가입은 만 14세 이상이다.** 만 14세 미만의 가입은 받지 않는다.
2. **법정대리인 동의를 받는 길은 만들지 않는다.** 만 14세 미만을 받지 않으므로 개인정보 보호법 제22조의2 의 동의 확인 절차를 짓지
   않는다 — 이 조가 우리 처리에 걸리는지의 판정은 적지 않는다(ADR 0182 · 0209). 조문 · 출처는 `docs/legal/under-14-draft.md` 「근거」.
3. **확인은 스스로 밝히는 것이다** — 가입 화면의 필수 확인 하나(「[필수] 만 14세 이상입니다.」 꼴)이고 나이를 재지 않는다. 재는
   길(본인확인 · 성인 확인)은 인연의 문이고(ADR 0214 · 약관 제19조의2) 가입에는 걸지 않는다(ADR 0225).
4. **Play 타겟층은 13–15 · 16–17 · 18세 이상이다** — Play 에 14세부터의 칸이 없어 13–15 를 고르고 13세는 약관 · 가입 확인이 막는다.
   답의 표와 출처는 `docs/ops/play-listing.md` 「타겟층 및 콘텐츠」.

## 아직 안 바뀐 것 — 글

약관 제8조 · 가입 화면 · 처리방침에 실을 줄은 `docs/legal/under-14-draft.md` 의 초안이고 **게시되지 않았다**. 다음 약관 · 처리방침 판
(#938 의 판)에 함께 싣는다 — 공개 출시 전이다(G-139). 그때까지 지금 게시본은 나이를 말하지 않는다.

## 근거

- 있는 정책 — ADR 0024 「남는 것」의 만 14세 줄(위) · ADR 0225(가입에 나이 확인 없음, 만 19세는 인연의 조건). 약관 제18조는 미성년자의
  결제 취소만 말하고 그대로 남는다
- 한국 서비스 — 헬로우봇 가입 화면 「[필수] 만 14세 이상입니다.」 · 「만 14세 미만은 회원 서비스를 이용할 수 없습니다.」
  (<https://hellobot.co/terms/service>, 2026-11-06). 읽지 못한 사례(점신 · 포스텔러 · 천명)는 `docs/legal/under-14-draft.md` 「근거」

## 고르지 않은 것

- **법정대리인 동의의 길을 짓기** — 동의 확인 · 대리인 연락 수단이 새로 들고, 사주 · 궁합 서비스에 만 14세 미만을 들일 까닭이 없다.
  비교한 한국 서비스(헬로우봇)도 받지 않는다.
- **가입에서 나이를 재기** — ADR 0225 가 가입의 문에서 본인확인을 걷었다. 재는 길은 인연에만 둔다.
