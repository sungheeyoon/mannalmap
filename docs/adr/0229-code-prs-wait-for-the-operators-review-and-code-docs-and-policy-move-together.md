# 코드 PR 은 운영자 검토 뒤에 머지되고, 코드 · 문서 · 정책은 같은 차례에 맞춘다

> 운영자 지시(2026-11-06): 「코드랑 문서랑 정책 따로 놀아」, 그리고 지금의 출시 흐름이 틀렸다. 조율자가 대화에서 받아 이 PR 에 넣게 했다.
> 그날 사정은 `docs/notes/2026-11-06-handoff-retro.md` 가 든다.
>
> 이 결정이 대체하는 것 — ADR 0152 (일부: 4 「운영자가 고치라고 한 일은 커밋 · PR · `--auto` 까지 묻지 않는다」 가운데 코드 PR 의 `--auto`)

## 정한 것

1. **출시 흐름은 넷이다.** 원본은 `docs/agents/delegation/coordinator.md` 「출시 흐름」이다.
   1. 일이 끝나면 에이전트가 PR 을 연다. 머지하지 않고 **운영자 검토**를 기다린다.
   2. 화면을 더했거나 흐름을 바꿨으면 조율자가 **아티팩트 보고**를 낸다. 실제 그림(전후 · 걸린 폭) · 잰 값 · 무엇을 왜 바꿨나(출처와 함께)를 싣는다.
      운영자는 diff 가 아니라 그 보고를 검토한다. 문구만 · 문서만 바뀐 PR 은 짧은 글 요약이면 된다.
   3. 운영자가 승인하면 CI 와 머지, 그다음 `docs/ops/runbook/deploy.md` 「묶음 배포」. 운영 배포는 지금처럼 「배포」 답을 받은 뒤다.
   4. 머지와 배포 기록(#770 댓글) 뒤에는 머지된 PR 의 워크트리와 로컬 가지를 **저절로** 걷는다. 도구는 #1025 가 든다.
2. **그대로 두는 것.** 문서 PR 은 열자마자 `--auto` 다(ADR 0121). 정해진 문구 한 줄은 바로 낸다(`docs/agents/delegation/decisions.md`).
   결정 점검표에 걸린 PR 은 전처럼 표로 묻는다. 권한 등급(ADR 0093)은 그대로다.
3. **코드 · 문서 · 정책은 같은 차례에 맞춘다.** 원본은 `docs/agents/delegation/done.md` 「끝났다는 것」이다.
   정책이 정해지거나 일이 끝나면 그 차례에 ADR · PRD · 간극 대장 · 운영 절차 · 문구 대장에 넣는다. 이슈 댓글이나 대화에만 있으면 끝나지 않은 것이다.
   이미 정한 정책(ADR 의 결정 · 약관과 고지 글 · 가격 · 환불 규칙 · 게시된 흐름)을 바꾸려면 운영자에게 먼저 묻는다. 정해진 정책을 따르는 데는 묻지 않는다.
   코드와 문서가 어긋나면 문서가 의도다. 코드를 고치고, 문서가 운영자 결정보다 낡았으면 문서를 고치고, 가를 수 없을 때만 화면 · 단추를 보이며 묻는다.

## 이 결정 전의 글과 어긋났던 자리

- `docs/agents/delegation/coordinator.md` 「조율자 세션」: 「운영자가 고치라고 한 일은 커밋 · PR · `--auto` 까지 묻지 않는다」, 에이전트에게 「결정이 아닌 PR 은 gate 뒤 `--auto` 머지까지」를 주라는 줄, 브리프의 「내보내기」 칸, 화면 세션은 「전후 스크린샷과 로컬 최소 셋으로 보고 머지한다」. 모두 코드 PR 을 운영자 검토 없이 머지했다.
- `docs/agents/delegation/unattended.md` 「무인 라운드」: 「gate 통과 뒤 `--auto` 머지 — 결정이 아닌 PR | 허용」과 「자동으로 고쳐도 되는 경계」의 `--auto`.
- `docs/agents/delegation/coordinator.md` 「라운드 끝 정리」: 워크트리를 걷기 전에 사람에게 한 번 확인했다. 머지되고 배포 기록까지 적힌 PR 의 것은 이제 묻지 않고 걷는다.

## 까닭

운영자가 지금의 흐름이 틀렸다고 했다. 위의 글대로라면 코드 PR 은 운영자가 검토하는 걸음 없이 머지까지 갔다.
같은 날 카카오 로그인이 운영에 섰는데 문서는 「꺼짐」이었고, 운영자가 대화로 정한 환불 규칙은 어느 파일에도 없었다. 다음 세션이 낡은 문서를 읽고 운영자에게 다시 물었다.

## 받아들인 것

- 머지가 운영자의 답만큼 늦어진다. 나란히 선 코드 PR 이 오래 열려 있으면 서로 충돌(`DIRTY`)할 일이 늘어난다. 머지 직전의 `npm run merge:sim` 은 그대로 돈다.
- 무인(밤) 라운드의 코드 PR 은 아침 보고에서 검토를 받을 때까지 머지되지 않는다.
