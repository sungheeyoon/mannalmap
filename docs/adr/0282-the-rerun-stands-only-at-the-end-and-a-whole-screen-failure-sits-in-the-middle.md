# 풀이 끝의 「다시 받기」는 수정 전 글에도 글 끝에만 서고, 화면 통째 실패는 가운데에 선다

> **운영자 결정 2026-11-27(낮, 앱 점검 열 건의 전후 그림을 보고).** 「A3 … 이거 다 좋은데 다시받기 버튼이 맨 위에 있는 건 별로여서 맨 아래 뒀었어.
> 맨 아래 있으니 지워도 될 듯」 · 「실패꼴은 처음 그림인 가운데 정렬이 더 좋지 않냐?」
>
> 이 결정이 대체하는 것 — ADR 0133 (일부: 덧의 「수정 전 글이면 다시 받기는 머리의 주 단추로 남는다」) · ADR 0281 (일부: 「화면 통째 실패는 실패 줄 하나」의
> 자리 — 글자 · 단추는 그대로, 자리만 가운데)

## 정한 것

1. **글이 있을 때 「다시 받기」는 수정 전 정보로 만든 글이어도 글 끝에만 선다** — 보내기와 반반(보내기가 없으면 혼자 주 단추). 머리의 주 단추를 걷는다.
   수정 전이라는 사실은 결과 화면 머리의 안내 줄(`READING_STALE_NOTE`)이 말한다. 웹(`app/me/reading/panel.tsx`) · 앱(`mobile/src/reading/panel.tsx`) 같다.
2. **화면 통째 실패는 화면 가운데에 선다** — 그 화면에 실패 말고 설 것이 없을 때(맨 위 줄 · 제목 밖에). 실패 줄(`FailureLine`)의 글자와 단추는
   그대로이고 자리만 가운데다 — 처음 읽는 동안 오행 다섯 점이 서던 자리, 남은 본문 높이의 세로 · 가로 가운데다(`FailureLine` 의 `whole`). 글이 두 줄로
   꺾이면 줄마다 가운데다. 화면 한쪽의 부분 실패(누름 실패 · 칸 하나의 실패 · 다른 것이 선 화면의 한 칸)는 제자리 그대로다. 웹 · 앱 같다.
   - 앱(`mobile/src/ui/failure-line.tsx`) — 관문의 껍데기 · 풀이 보관함 · 풀이 · 소식 · 저장한 사람 · 사람 화면 · 궁합 결과 · 궁합 탭의 고르기(제목
     「궁합 새로 보기」 아래). 결제 내역은 못 읽어도 환불 신청 칸이 서 있어 부분 실패다.
   - 웹(`app/ui/failure-line.tsx`) — 계정을 못 읽은 화면(`AccountNotice` 가 본문의 전부인 홈 · 풀이 보관함 · 사람 화면 · 설문 · 프로필, 제목 아래 그것뿐인
     저장한 사람 · 소식)과 소식을 못 읽은 화면. 화면을 못 그린 오류 경계(`app/error-screen.tsx`)는 원래 가운데다.
   - 닫힌 인연 · 채팅의 화면은 열 때 맞춘다(G-192).

## 까닭

1. 「안 A」(2026-10-26)가 다 읽은 뒤에 하는 일을 글 끝에 모았는데, 수정 전 글만 예외로 머리에 주 단추가 남아 있었다(시안 3차 warm 의 「읽기 전에 정한다」).
   운영자는 위의 단추를 원래 아래로 내린 것으로 보고 있었고, 같은 일에 손잡이는 하나라 끝에 있으면 위는 필요 없다고 정했다.
2. 화면 전체가 실패만 말할 때는 빈 화면 · 기다림 같은 다른 「화면 전체의 상태」처럼 가운데에 서는 쪽이 낫다고 운영자가 골랐다(점검 전후 그림에서 고친 뒤의
   왼쪽 정렬과 고치기 전의 가운데를 나란히 보고). 꼴(붉은 한 줄 + 다시 시도)은 ADR 0281 그대로 한 벌이다. 운영자가 본 그림은 앱 관문이었지만 같은 처지의
   화면이 저마다 다른 자리에 서면 어느 쪽이 이 서비스의 「못 읽은 화면」인지 사용자가 정하게 된다(ADR 0109 추기 2026-10-09 의 안내 화면과 같은 까닭) —
   그래서 실패 말고 설 것이 없는 화면은 앱 · 웹 모두 같은 자리다. 웹의 같은 자리는 계정 · 소식을 못 읽었을 때 왼쪽 위에 섰고(앱 관문이 따른 꼴), 화면을
   못 그리면 서는 오류 경계는 이미 가운데였다.

## 받아들인 것

- 두 줄로 꺾인 실패 글은 줄머리가 흔들린다 — 안내 화면의 「가운데 판 · 왼쪽 글」(ADR 0109 추기 2026-10-09)과 다르다. 실패 줄은 한두 문장이라 줄마다
  가운데가 빈 화면 · 기다림의 축과 맞다.
- 웹의 계정 실패 줄은 화면마다 `whole` 을 넘겨야 가운데다(`AccountNotice` 는 정지 · 탈퇴 대기 상자도 그려, 부르는 자리가 본문의 전부인지 안다).
  새 화면이 계정을 못 읽은 안내를 본문의 전부로 세우면 `whole` 을 넘긴다.
