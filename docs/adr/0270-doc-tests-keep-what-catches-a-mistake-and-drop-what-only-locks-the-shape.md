# 문서를 재는 시험은 실수를 막은 것만 남기고, 문서의 꼴만 잠그는 것은 걷는다

> **운영자 결정 2026-11-26**(조율자가 감사 결과를 물었고, 답을 브리프로 전함) — `scripts/code-rules.test.ts` 가운데 문서의 꼴만 잠그는
> 검사를 두고 「진짜 실수를 막는 것은 남기고 꼴만 재는 것은 걷는다」. ADR 0264 「정한 것」 3 의 「시험도 같은 잣대로 본다」를 옮긴다.
> 결정 점검표의 「검증 · 배포의 문턱」(무엇을 시험이 확인하나)에 걸린다.

> 「색인 「절」 칸이 파일의 절을 차례대로 다 드는 시험은 그대로다」와 「정한 것」 4(노트의 놓은 자리는 시험이 재지 않는다), ADR 0264
> 「정한 것」 5 의 「`CLAUDE.md`(600 바이트)」.

## 잰 것 (2026-11-26, main `cbe0aafb`)

- **감사가 짚은 후보는 스물둘 남짓이다.** 문서 모양이 바뀌면 붉고 실제 실수는 거의 못 막는 검사다 — 색인의 꼴(머리말과 「차례」뿐 ·
  절을 차례대로 다 든다 · 정의 문장이 없다), 절 번호가 끊기지 않는다, 기록 파일의 첫 줄, 노트 줄 끝의 `→ 놓은 자리`, 역할 문서 칸의 차례,
  역할 문서 여덟이 글자 그대로 들던 여는 말 한 줄(일부 대체된 ADR 0147 을 인용).
- **판정은 그 검사를 더한 커밋과 `git log -S` 로 했다.** 실제로 난 일이 기록에 있으면 남기거나 좁히고, 꼴의 일관성뿐이면 걷는다.
  - 기록이 있는 것: 머지된 ADR 에 추기가 0240 뒤에도 16 개 더 붙었다(ADR 0260 「잰 것」). 간극 대장 한 줄이 만 자를 넘었다(G-23,
    메모 칸 500 자의 까닭). 역할 문서 「닿을 때 여는 것」에 목록 밖 문단 6 KB 가 초록으로 지났다(ADR 0254, #1175 검토). `CLAUDE.md` 가
    원본을 다시 말하며 3,214 바이트로 불었다(#511). 같은 번호를 두 PR 이 잡았다(ADR 0201 셋 · 대장 「1 2 2」, ADR 0260).
  - 기록이 없는 것: 색인 · PRD · 용어집의 꼴 검사는 한 장을 폴더로 나누던 날(2026-10-05, #484 ~ #494) 「같은 것을 새 경로에서 잰다」며 섰고,
    그 뒤 이 검사만 잡은 실수는 없다. 노트의 놓은 자리 검사는 파일 이름 하나면 지나 「→ 「다음에 보기」」 같은 우회를 조이는 데 썼다
    (ADR 0260 「정한 것」 4) — 교훈이 실제로 놓였는지는 못 잰다.
- **매 턴 실리는 것은 `CLAUDE.md`(301 바이트)만이 아니라 그것이 끌어오는 `AGENTS.md`(2,619 바이트)까지다.** 600 바이트 검사는 작은 쪽만 쟀다.

## 정한 것

1. **문서를 재는 검사는 「빼면 어떤 실수가 들어오나」에 답이 있을 때만 둔다.** 답은 가리킴(경로 · 절 · 앵커 · 링크가 있다), 경계 · 비밀,
   두 자리가 하나를 가리킨다(같은 번호 둘), 실제로 불었던 자리의 크기, 줄어들기만 하는 지문 목록이다. 꼴의 일관성은 답이 아니다.
2. **걷는 것** — 주석 날짜 목록의 정렬, 용어집 색인의 정의 문장 · 절 번호 1–10 · 표의 자리, PRD 색인의 요구 문장 · 본체 절 번호 0 부터,
   ui 역할의 무리 선택지, 대장의 「## G-nn 기록」 절 · 기록 파일의 첫 줄 · PRD 본체의 개정 기록, 읽기량 셈의 내부 같음 둘(셈의 단위 시험은
   `scripts/read-budget.test.ts` 가 든다), 노트의 `→ 놓은 자리`(규칙은 `docs/agents/delegation/notes.md` 「세션 기록」에 그대로 선다),
   색인 여섯의 「머리말과 「차례」뿐」, 「닿을 때 여는 것」의 여는 말 한 줄(역할 문서 여덟에서 그 문장을 지웠다).
3. **좁히는 것.**
   - 문구 대장: 색인 「절」 칸이 파일의 절을 다 드는지는 걷고, 대장 전체의 번호(`## NN`)가 어느 파일에서나 같은 제목이며 47 을 넘지 않는지만 잰다.
   - 색인 여섯의 「절」 칸: 차례 · 빠짐없음은 걷고, 부른 절이 그 파일에 있는지만 잰다.
   - 역할 문서: 칸의 차례는 걷고, 손대기 전에 여는 두 칸(「지킬 것」 · 「먼저 읽는 것」)이 있는지, 「닿을 때 여는 것」 앞까지 8,000 바이트,
     그 칸에는 목록 줄만 서는지를 잰다.
   - 매 턴 싣는 크기: `CLAUDE.md` 600 바이트를 걷고 `CLAUDE.md` 와 `AGENTS.md` 를 합쳐 **4,000 바이트**로 잰다(지금 2,920). `CLAUDE.md` 가
     `@AGENTS.md` 로 여는지는 그대로다 — 빠지면 `AGENTS.md` 가 안 실린다.
4. **남기는 것** — ADR 추기 수 지문과 그 셈의 단위 시험, 주석 날짜 지문과 출처 날짜 판정, 대장 무리 파일의 새 절 번호(남의 이름 · 같은 번호 둘),
   대장 메모 칸 500 자, 대장의 기록 링크 ↔ 기록 파일 일대일. 감사가 값을 한다고 본 나머지(ADR 참조 실재 · 경로 · npm 스크립트 · 권한 표 =
   settings · 개인정보 꼴 · 링크 · 경계 · 비밀 · 탈출구 지문)는 손대지 않았다.

## 치르는 값

- 색인이 파일의 새 절을 안 들거나 차례가 어긋나도 붉지 않다 — 읽는 이는 파일의 머리를 본다. 색인이 **없는** 절을 부르면 여전히 붉다.
- 용어집 · PRD 의 절 하나가 통째로 사라져도 이 시험은 모른다 — 그 절을 가리키는 쪽(대장의 `§`, 역할 문서의 「절」, 색인의 「절」 칸)이 붉어진다.
- 노트에 「→ 다음 retro 로」가 다시 설 수 있다. 회고(`/retro`)가 같은 자리에서 두 번 넘어졌을 때 그 자리를 찾는다.
- `AGENTS.md` 에 줄을 더하는 PR 은 4,000 바이트 안이어야 한다 — 넘으면 원본으로 옮길 줄을 찾는다.

## 버린 것

- **`CLAUDE.md` 600 바이트를 그대로 둔다** — 매 턴 싣는 것의 열에 아홉인 `AGENTS.md` 를 안 잰다.
- **`AGENTS.md` 만 따로 잰다** — `CLAUDE.md` 로 줄을 옮겨 피할 수 있다. 실리는 것은 둘의 합이다.
- **꼴 검사를 「보고」로 돌린다**(붉히지 않고 찍기만) — 아무도 안 읽는 출력이 하나 늘 뿐이다. 읽기량 예상치가 이미 그 자리다(ADR 0177).
