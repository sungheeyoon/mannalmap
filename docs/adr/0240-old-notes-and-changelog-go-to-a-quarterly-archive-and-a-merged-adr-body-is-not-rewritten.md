# 지난 노트와 개정 기록은 분기마다 보관함으로 옮기고, 머지된 ADR 본문은 다시 쓰지 않으며, 사실 하나는 원본 한 곳에 있다

> **운영자 결정 2026-11-08**(조율자가 옮김) — 권고안 넷을 그대로 골랐다: 분기 보관함 · ADR 추기 금지의 예외는 사실 정정 · 링크 · 오타만 ·
> 사실의 원본 표는 아래 넷 · 첫 이동은 혼자 도는 라운드. 결정 점검표의 「검증 · 배포의 문턱」(무엇을 시험이 확인하나 · 읽기량을 어떻게 세나)에 걸린다.
> 실제 파일 이동은 이 PR 에 없다 — 다른 PR 이 열려 있지 않은 혼자 도는 라운드에서 한다(G-154).

## 무엇이 무거웠나

2026-11-08 감사가 잰 값이다.

- `docs/product/prd-changelog.md` 는 305,024 바이트이고 끝에 쓰기만 한다. `docs/notes/` 는 노트 98개 · 1.2MB 다. 둘 다 「지금」을 말하지 않는데
  `docs/notes/README.md` 의 차례 시험 · 공유 번호 검사(`scripts/shared-numbers.mjs` 가 개정 기록의 `G-nn` 을 센다) · 문서 전체의 ADR 참조 시험이
  매번 통째로 읽는다.
- **머지된 ADR 을 추기로 계속 고친다.** ADR 0109 는 머지 뒤 커밋 서른한 번으로 고쳐져 추기 · 덧 절이 열아홉이고 45,747 바이트다. 무엇이 지금 유효한지 보려면 처음부터 끝까지 읽고
  추기끼리 견줘야 한다 — 색인(`docs/adr/README.md`)의 한 줄이 그 ADR 의 지금 모양을 다 말하지 못한다. ADR 0211 의 추기 2026-11-06 은 실제
  코드와 다른 문장을 들고 있었다(2026-11-08 정정).
- **같은 사실이 여러 곳에 날짜째 있다.** 배포 SHA · DB 판본(`migration list` 의 remote) · 권한을 켜고 끈 날이 간극 대장 칸 · 운영 절차 · 위임
  규약 · 노트 · 세션 메모에 따로 적혀, 하나가 바뀌면 나머지가 낡는다. 위임 규약의 등급 3 이력은 2026-11-08 에 덜어냈다(#1081).

## 정한 것

1. **보관함 — 분기마다.** 분기 첫 주에 지난 분기의 노트와 개정 기록의 지난 분기 절을 `docs/notes/archive/<연도>-Q<n>/` ·
   `docs/product/prd-changelog/archive/<연도>-Q<n>.md` 로 옮긴다. 보관함은 기록이라 옛 경로째 둔다(ADR 0090 「잠그지 않은 것」과 같은 결).
   - 노트 차례(`docs/notes/README.md`)는 보관함 폴더 한 줄씩만 든다 — 시험은 보관함 안의 파일을 하나하나 세지 않는다.
   - 읽기량 셈(`scripts/read-budget.mjs`)은 보관함을 세지 않는다. 지금도 노트 · 개정 기록은 고정 목록에 없으므로 바뀌는 수는 0 이다 —
     이 줄은 앞으로 누가 보관함을 역할 문서에 링크해도 세지 않는다는 뜻이다.
   - **공유 번호 검사는 보관함까지 센다.** 닫힌 `G-nn` 은 개정 기록에만 남으므로, 보관함을 빼면 닫은 번호를 다시 내준다(ADR 0238 의 4).
   - ADR 참조 시험(「없는 ADR 번호」)은 보관함도 읽는다 — ADR 은 지우지 않으므로 붉을 일이 없다.
2. **머지된 ADR 본문은 다시 쓰지 않는다.** 정책이 바뀌면 새 ADR 을 쓰고, 옛 ADR 머리에 `> 후속 결정: ADR NNNN — …` 또는
   `> 후속 결정(일부): …` 한 줄만 단다(`docs/agents/domain.md` 「Writing an ADR」 그대로). 추기(`## 추기 …`)는 더 달지 않는다.
   예외는 둘 — **사실 정정**(정책은 그대로이고 ADR 의 문장이 코드와 다를 때, 짧은 `## 정정 …` 절 하나)과 **깨진 링크 · 오타**.
   이미 있는 추기는 그대로 둔다 — 걷어 내지 않는다.
3. **사실 하나는 원본 한 곳.** 날짜가 붙어 바뀌는 운영 사실은 아래 자리에만 적고, 다른 문서는 그 자리를 가리킨다.

   | 사실 | 원본 |
   | --- | --- |
   | Production SHA · smoke | #770 의 가장 최근 배포 댓글(`docs/ops/runbook/deploy.md` 「묶음 배포」 5) |
   | 운영 DB 판본(`migration list` remote) | 같은 배포 댓글 — 배포 없이 `db push` 만 했으면 #770 에 그 값을 따로 한 줄 |
   | 권한 잠금을 켜고 좁힌 날 | ADR 0093 — 위임 규약은 지금의 표만 든다 |
   | 지금 출시 단계 | `docs/product/prd/roadmap.md` §7.0 의 「(지금)」 |

   간극 대장 칸 · 노트 · 세션 메모는 그 값을 옮겨 적지 않고 「#770 최근 배포 댓글」처럼 자리로 가리킨다.

## 견준 것

- **개정 기록을 지운다** — 닫힌 `G-nn` 과 PRD 의 계보가 그 파일 하나에만 있다. 지우면 공유 번호 검사가 닫은 번호를 다시 내준다. 옮기기만 한다.
- **노트를 해마다 옮긴다** — 한 해에 노트가 수백이 되면 차례 표가 다시 무겁다. 분기가 라운드 노트 「최근」 표의 여덟 줄과 맞는다.
- **ADR 추기를 허용하되 색인 줄을 함께 고친다** — 지금 하는 방식이고, 색인 한 줄이 추기 열아홉을 담지 못해 ADR 0109 가 이렇게 됐다.

## 운영자의 답(2026-11-08)

| 물음 | 답 | 고르지 않은 안 |
| --- | --- | --- |
| 보관함 주기 | **분기** | 해마다 · 크기(예: 200KB)를 넘을 때 |
| ADR 추기 금지의 예외 | **사실 정정 · 링크 · 오타만** | 추기를 계속 허용하고 색인 줄만 맞춘다 |
| 사실의 원본 표 | **위 「정한 것」 3 의 넷 그대로** | 줄을 더하거나 뺀다 |
| 옮기는 첫 라운드 | **이 ADR 이 머지된 다음, 다른 PR 이 열려 있지 않은 혼자 도는 라운드** | 2027-Q1 첫 주 |

## 받아들인 것

- 보관함으로 옮기는 날, 옛 경로를 가리키는 지금의 문서(역할 문서 · 위임 규약 · 런북 · 코드 주석)의 링크를 함께 고쳐야 한다 —
  `docs/agents/delegation/notes.md` 「경로가 옮겨지면」의 차례다. 코드 주석의 노트 경로가 수십 곳이라 그 라운드는 혼자 돈다.
- 추기를 금지하면 작은 정책 변경에도 새 ADR 이 하나씩 는다. 번호는 늘지만 한 ADR 이 한 결정을 말한다.
